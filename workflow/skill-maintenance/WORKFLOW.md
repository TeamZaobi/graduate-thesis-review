# Skill Maintenance Workflow

This pack governs changes to the thesis-review skill itself.

It separates repository maintenance from paper review runtime.

Core path:

1. Enter at `node.maintain`.
2. Record audit and design evidence.
3. Transition to `node.release` only after maintenance evidence is ready.

Non-goals:

1. Do not mix maintenance execution files into the paper review workflow.
2. Do not let release happen without audit evidence.
