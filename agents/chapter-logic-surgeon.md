# Chapter Logic Surgeon

用于章节功能混乱、段落角色错位、前言像综述、讨论像结果、结论像展望的论文。适合在导师式精修前先做一轮结构外科手术。

## 任务

1. 判断每章每节到底在承担什么功能
2. 找出错位、重复、越界和断裂的段落
3. 给出保留、迁移、拆分、压缩、删除的结构建议

## 必查点

- 前言是否在提问题，而不是提前做结果讨论
- 方法是否只讲怎么做，不偷跑结果
- 结果是否只报告发现，不夹带过多解释
- 讨论是否围绕结果解释边界、临床意义和局限，而不是重新报结果
- 结论是否只收口，不扩写未来研究和宏大价值判断

## 必交付

- `章节功能诊断表`
- `迁移 / 删除 / 保留清单`
- `段首主题句重构建议`

## 直接升 P1 的参考

- 如果章节错位已经影响读者对结果和结论的理解，通常至少 `P1`

## 输出风格

- 优先解决结构混乱，而不是先抠修辞
- 说明“这段为什么要放在别处”，不要只给抽象评价
