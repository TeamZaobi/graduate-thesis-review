# 工作量充足性判定标准

论文审查语境下，"工作量"不是毕业资格审查用语（字数、学分、发表要求），而是一个方法论问题：

> **论文呈现的证据链，能否支撑它宣称的结论？**

这份文件定义"证据-结论匹配度"的判定标准，供 `workload-assessment-agent` 执行时参照。

---

## 1. 核心概念区分

| 论文审查（本文关注） | 毕业资格审查（不在此处判断） |
|---|---|
| 样本量是否支撑统计结论强度 | 投入时间够不够半年/一年 |
| 测量指标是否覆盖宣称的机制 | 字数是否达到2万 |
| 图表是否支撑关键结论 | 是否发表SCI/EI论文 |
| 对照设置是否支撑疗效宣称 | 学分是否修满 |

**判断原则**：不说"工作量不足"，说"证据不足以支撑当前结论"。后者更精确，也更可操作。

---

## 2. 四个核心匹配维度

### 维度一：样本量-结论匹配度

**P0（硬伤）**
- 样本量无法支撑主要结局的统计结论
- 分母与分析集不匹配（方法写30人，表格只有28人，无说明）
- 多重比较未调整却宣称确证性结论

**P1（会被追问）**
- 样本量未做 power analysis 但宣称充分
- 亚组分析样本过小但做确定性宣称

**P2（规范加固）**
- 未报告效应量和置信区间
- 样本量估算依据未在方法中说明

---

### 维度二：测量深度-机制宣称匹配度

**P0（硬伤）**
- 仅测行为指标却宣称神经机制
- 单时间点却宣称长期效应
- 缺乏关键对照却宣称特异性

**P1（会被追问）**
- 测量指标覆盖不足但机制链条完整
- 时间点稀疏但趋势一致

**P2（规范加固）**
- 未报告测量误差/信度
- 测量时间窗口未明确

---

### 维度三：图表证据-论点强度匹配度

**P0（硬伤）**
- 关键结论无图表支撑
- 图表与正文结论互相矛盾
- 图号错位导致证据链断裂

**P1（会被追问）**
- 次要结论缺乏图表
- 图表注释不足以支撑解释

**P2（规范加固）**
- 图表视觉呈现不够清晰
- 缺乏关键对比的标注

---

### 维度四：对照设置-疗效宣称匹配度

**P0（硬伤）**
- 无对照却宣称疗效
- 对照组设计不合理却做确证比较
- 假刺激/安慰剂未标准化却宣称盲法有效

**P1（会被追问）**
- 对照组只做常规护理但做优效宣称
- 缺乏假刺激/安慰剂说明

**P2（规范加固）**
- 对照组描述不够详细
- 共干预风险未充分讨论

---

## 3. 不同研究类型的匹配度差异

### 量化研究（RCT、观察性、诊断）

按上述四个维度全量评估。样本量-结论匹配度是核心锚点。

### 质性研究（访谈、扎根理论、现象学）

样本量不适用数量标准，改用以下锚点判断证据充分性：

- **主题饱和度**：新访谈是否不再产生新主题
- **三角验证**：是否有多种数据来源相互印证
- **反例讨论**：是否主动呈现与主题相悖的案例
- **数据来源多样性**：是否综合了访谈、观察、文档等多种来源
- **研究者反思性呈现**：是否说明研究者立场对数据解读的影响
- **原始引语/节选的充分性**：是否提供足够的原始数据支撑主题归纳

质性研究的"证据不足"通常表现为：主题归纳缺乏原始引语支撑、只有单一数据来源、未讨论反例。

### 混合方法研究

分别对量化部分和质性部分做匹配度判断，再额外检查：
- 两种方法的结论是否整合，还是各说各话
- 量化结果和质性发现是否相互印证或解释

## 4. 安全降级词表（双向）

### 降级表述（结论强度过高时使用）

| 原表述 | 安全降级 |
|---|---|
| 证实/证明 | 提示/支持 |
| 显著改善 | 有改善趋势 |
| 神经机制 | 可能的神经路径 |
| 长期效应 | 短期随访内的效应 |
| 特异性疗效 | 在当前对照条件下的差异 |
| 普适性结论 | 在本研究样本中的初步发现 |

### 局限性诚实表达（证据不足时使用）

| 问题描述 | 诚实表达 |
|---|---|
| 样本量限制了统计检验力 | "在当前样本量下，初步信号支持……，需更大样本验证" |
| 未达到统计显著性 | "趋势提示……，需更大样本验证" |
| 缺乏对照组 | "本研究为单组前后对照，疗效归因需谨慎" |
| 随访时间短 | "当前随访窗口内观察到……，长期效应尚不明确" |
| 测量指标有限 | "本研究以……为代理指标，直接测量……有待后续研究" |
| 质性研究样本小 | "本研究聚焦于……群体的深度理解，结论的可迁移性需在其他情境中验证" |

---

## 5. 常见不匹配模式

- **过度机制化**：行为数据 → 宣称神经机制（缺乏神经影像或电生理支撑）
- **过度普适化**：单中心小样本 → 宣称普遍规律
- **时效错配**：4周随访 → 宣称"长期改善"
- **对照稻草人**：对照组只做常规护理 → 宣称设备"优效"（无法排除注意力效应）
- **图表孤岛**：关键结论只在正文，图表只展示次要指标

## 6. 与现有 agent 的边界

| 检查项 | 负责 agent |
|---|---|
| 统计方法是否正确 | `stats-endpoint-agent` |
| 图号/图题/图注错误 | `figure-forensics-agent` |
| 干预完整性与对照可信度 | `epi-rct-agent` |
| **跨维度证据-结论匹配度** | `workload-assessment-agent`（本模块） |
| **安全降级表述建议** | `workload-assessment-agent`（本模块） |

当检查项已被其他 agent 覆盖时，直接引用其结论，不重复判定，只做"匹配度"层面的二次解读。
