# 前沿检索与创新定位闸门

当导师建议已经超出局部改稿，进入“创新性、最新进展、领域定位、未来升级路径”时，加载此文件。

## 1. 触发条件

以下任一条件满足时，触发前沿层：

- 用户要求判断创新性、前沿性、研究价值或答辩定位
- 讨论部分需要与最新研究进展对标
- 论文的创新点表述需要确认是否仍成立
- 导师建议需要回答“当前领域最新最强进展是什么”

## 2. 检索顺序

优先级固定为：

1. 官方指南、共识、报告规范
2. 方法学一手论文
3. 最新高质量系统综述或综述
4. 最新高质量原始研究

## 3. 允许用途

外部知识只能用于：

- `前沿知识简报`
- `创新定位判断卡`
- 讨论部分的边界收缩或重定位
- 未来研究方向建议
- 答辩口径中的创新定位

## 4. 禁止用途

- 用外部知识替代论文自身证据
- 用最新文献补造论文未做过的分析、实验或结果
- 把前沿进展直接写成“本研究已经达到”
- 把领域趋势包装成论文当前版本已经具备的创新性

## 5. 前沿层最少产物

### `前沿知识简报.md`

至少回答：

- 当前领域最新最强进展是什么
- 当前论文哪些表述已经落后、过强或定位不准
- 哪些最新规范会改变讨论或答辩表达

### `创新定位判断卡.md`

至少回答：

- 当前论文的创新点是 `成立 / 偏弱 / 过时 / 需重写`
- 依据是什么
- 建议进入正文、答辩还是未来研究的哪一层

## 6. 与导师分层的关系

- `L1-L3` 可以不触发前沿检索
- `L4` 默认至少需要一份前沿知识简报或等价结构
- 前沿层只改变定位、边界和升级路径，不改变论文事实真源
