# 专业领域路由器

每次审查任务开启时，先执行本文件定义的识别流程，再决定加载哪些专项模块、屏蔽哪些模块。

**核心原则**：医学大学科下的小学科隔行如隔山。错误加载不相关的专项模块，会导致用错误的标准评判论文，甚至给出相互冲突的建议。

---

## 1. 专业识别方法

从以下位置依次读取，优先级从高到低：

1. **用户明确告知**：用户直接说"这是心血管内科论文"、"中西医结合方向"
2. **论文封面/致谢**：学院、科室、导师专业方向
3. **期刊/会议名称**：投稿目标期刊往往直接标明领域
4. **摘要关键词**：MeSH 词、中文关键词
5. **研究对象描述**：患者诊断、疾病名称、干预手段
6. **结局指标名称**：特定量表、生物标志物、影像指标

识别后，明确输出两个层级：

```
大学科：[内科 / 外科 / 康复医学 / 中医 / 护理 / 公共卫生 / ...]
小学科：[心血管内科 / 脑卒中康复 / 中西医结合肿瘤 / ...]
```

如果无法确定，直接问用户："这篇论文属于哪个科室/专业方向？"，不要猜测后默默加载错误模块。

## 3. 路由规则

### 加载规则

- 识别到对应专业 → 加载对应专项文件
- 同一论文可能跨两个专业（如"心脏康复"）→ 同时加载两个专项文件，但在冲突点以更严格的标准为准
- 专项文件不存在 → 执行第4节流程

### 屏蔽规则

屏蔽的目的是防止用错误领域的标准评判论文，不是降低审查严格度。

**心血管专项激活时**：
- 不强制要求康复剂量三要素（每次时长/每周频次/总周数）
- 不套用 fNIRS/EEG 信号链检查
- 不用康复生态效度标准评判手术或介入研究

**中医/中西医结合专项激活时**：
- 不把"无法实现双盲"直接判为 P0 硬伤（需结合领域惯例评估）
- 不要求安慰剂必须与真实干预外观完全一致（针灸假针等有领域特定标准）
- 不用西医病理机制标准评判中医证候分类的合理性

**纯工程/算法类论文**（无临床受试者）：
- 屏蔽伦理审批、知情同意、CONSORT 等临床合规检查
- 屏蔽样本量 power analysis 要求
- 重点转向工程可复现性和算法验证

## 4. 未知专业的处理流程

当论文专业无对应专项文件时：

**第一步**：用通用框架（`clinical-study-types.md` + `review-rubric.md`）先做快筛，识别明显硬伤。

**第二步**：触发 deep-research，查询以下内容：
```
查询目标：
1. [专业名称] 领域硕士/博士论文的方法学规范和常见问题
2. 该领域主流报告规范（如 CONSORT 扩展版、领域特定指南）
3. 该领域核心结局指标和金标准测量方法
4. 近3年该领域研究热点和方法学争议
```

**第三步**：将 deep-research 结果整理为新专项文件，存入 `references/specialty-[领域名].md`，并更新本路由表。

**第四步**：告知用户："已为 [专业] 创建专项参考文件，后续同类论文可直接加载。"

## 5. 专项文件时效性管理

每个专项文件头部应标注：

```
最后更新：YYYY-MM
适用范围：[专业领域]
主要参考规范：[指南名称 + 版本年份]
```

以下情况建议触发 deep-research 更新专项文件：

- 文件创建超过18个月
- 用户提到"最新指南"或"新版规范"
- 论文引用的指南版本比专项文件中记录的更新
- 审查中发现专项文件的标准与论文所引用的领域规范有明显出入

更新时不要整体覆盖，只更新有变化的部分，并在文件头部更新日期。

