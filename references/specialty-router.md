# 专业领域路由器

每次审查任务开启时，先执行本文件定义的识别流程，再决定加载哪些专项模块、屏蔽哪些模块，并且**先过专项手册完备性 gate**，不要因为已有 `specialty-*.md` 就默认它足够。

核心原则有两条：

1. 医学大学科下的小学科隔行如隔山，错用专项会直接带来错误判断
2. “已有专项文件”不等于“当前论文所需规则已经覆盖完”

专项完备性 gate 见 [specialty-manual-readiness-gate.md](./specialty-manual-readiness-gate.md)，共享专项高标准见 [specialty-manual-standard.md](./specialty-manual-standard.md)。

## 1. 专业识别方法

从以下位置依次读取，优先级从高到低：

1. 用户明确告知：如“这是心血管内科论文”“这是中西医结合方向”
2. 论文封面、致谢、学院、科室、导师专业方向
3. 投稿期刊、目标会议或培养单位
4. 摘要关键词、MeSH 词、学科标签
5. 研究对象描述：疾病名称、患者来源、干预手段
6. 结局指标和设备名称：量表、生物标志物、影像、器械、药物

识别后，至少明确两个层级：

```text
大学科：[内科 / 外科 / 康复医学 / 中医 / 护理 / 公共卫生 / ...]
小学科：[心血管内科 / 脑卒中康复 / 中西医结合肿瘤 / ...]
```

如果仍无法确定，直接问用户“这篇论文属于哪个科室/专业方向？”，不要默默猜测。

- 神经内科（临床，区别于神经工程）

- 内分泌科 / 代谢病

- 儿科 / 新生儿科
- 妇产科

## 3. 先过专项手册完备性 Gate

识别到专业后，立即加载 [specialty-manual-readiness-gate.md](./specialty-manual-readiness-gate.md)，把当前专项状态判成：

- `complete`
- `partial`
- `missing`

判断时至少同时看六个维度：

1. 专业和亚专业是否匹配
2. 当前研究类型是否被覆盖
3. 当前毕业论文阶段是否被覆盖
4. 当前论文暴露出的关键方法学问题，现有手册能否直接回答
5. 当前学科的审查语域是否已覆盖，对外交付物是否已有自然表述
6. 当前论文是否需要启动多专家独立审计，还是单专项深审已经足够

如果不做这一步，就不要直接进入深审。

### 3.1 什么时候必须启动多专家独立审计

以下任一情况满足时，不要只写“已命中多个专项”就继续往下走；先把多专家审计节点立住：

- 主结论同时依赖 `流行病学/研究设计`、`生物统计`、`具体临床领域` 三类判断
- 因果识别、估计对象和专病终点解释三者中任意两者出现明显耦合
- 研究类型主轴和专病语境主轴并存，例如“真实世界因果推断 + 心血管结局”或“设备康复干预 + 神经行为结局”
- 不同代理、不同台账或不同外部意见对同一核心结论给出跨领域冲突
- 只靠一个专项文件已经无法同时回答“设计是否成立、统计是否成立、临床解释是否成立”

启动时至少回答：

- `domain_stack`
- `primary_loop`
- `supporting_loops`
- `independent_audit_required`
- `required_expert_checks`

这些字段默认写入 `reviews/专业手册完备性判断.md`。如果当前没有对应共享专项，则在 `reviews/专业专项补充说明.md` 中补齐缺失闭环。

如果 `independent_audit_required = yes`，进入深审前先确定：

- 哪些闭环各自独立出 provisional judgment
- 谁负责最后做跨闭环收敛
- 哪些冲突解决前不得给送审 / 答辩 readiness

## 4. 加载规则

### `complete`

- 加载对应专项文件
- 按专项文件 + 通用框架进入正常审查

### `partial`

- 加载对应专项文件
- 继续用通用框架做快筛
- 同时补 `reviews/专业手册完备性判断.md`
- 再补 `reviews/专业专项补充说明.md`
- 同时补本学科常用审查用语和建议替换词
- 本轮先用论文级补充支撑深审，回合结束后再判断是否升级共享专项

### `missing`

- 不强套相邻专项
- 先用 `clinical-study-types.md + review-rubric.md` 做通用快筛
- 生成 `reviews/专业手册完备性判断.md`
- 再补 `reviews/专业专项补充说明.md`
- 如内容具有可复用性，再新建共享 `specialty-*.md`

### 多专项并载

- 同一论文可以同时命中两个专项，如“心脏康复”“肿瘤真实世界因果推断”
- 冲突点优先顺序：研究类型与识别边界 > 专业独有终点/干预标准 > 通用表达与展示标准
- 只要出现冲突，就必须在 `专业手册完备性判断` 中写明谁优先
- 多专项并载不等于已经完成多专家独立审计；只要主结论横跨两个以上闭环，仍要单独写 `domain_stack / primary_loop / required_expert_checks`

## 5. 屏蔽规则

屏蔽的目的是防止误用标准，不是降低严格度。

### 心血管专项激活时

- 不强制要求康复剂量三要素，除非论文本身是心脏康复
- 不套用 `fNIRS/EEG` 信号链检查
- 不用康复生态效度标准评判纯手术或药物研究

### 中医 / 中西医结合专项激活时

- 不把“无法实现双盲”直接判为 `P0`
- 不要求安慰剂与真实干预外观完全一致
- 不用西医病理机制标准否决中医证候分类

### 公共卫生 / 观察性因果推断专项激活时

- 不强行要求随机、假刺激、分配隐藏等 `RCT` 语言
- 不套用康复或工程论文的设备透明度检查，除非论文真的有该证据链
- 重点转向 `estimand / time zero / confounding / positivity / censoring / competing risk / interaction`

### 纯工程 / 算法论文

- 屏蔽伦理审批、知情同意、CONSORT 等临床合规检查
- 屏蔽样本量 `power analysis` 要求
- 重点转向工程可复现性、验证集与外部验证

## 6. 未知专业或手册缺失时的处理流程

当论文没有对应专项，或现有专项被判为 `missing` 时：

### 第一步：不停审

- 用通用框架先做快筛，抓明显 `P0 / P1`
- 冻结审阅对象、版本真源、图表和补充材料入口

### 第二步：补专项信息

优先查：

1. 该专业硕士/博士论文的关键方法学规范和常见问题
2. 领域主流报告规范或扩展版
3. 核心结局指标与金标准
4. 近 3 年高频方法学争议
5. 该学科导师、学生和外审常用的审查表达，以及应避免的跨学科行话

### 第三步：决定落点

- 只够当前论文使用：写入 `reviews/专业专项补充说明.md`
- 已具备跨论文复用性：升级为共享 `references/specialty-[领域名].md`

### 第四步：共享专项升级后回跑

- 新建或重写共享专项后，运行 `scripts/check_specialty_manual.py`
- 需要时回跑第二阶段深审，避免“专项补上了，但结论还是旧的”

## 7. 专项文件时效性管理

每个专项文件头部都应标注：

```markdown
最后更新：YYYY-MM
适用范围：[专业领域]
主要参考规范：[指南名称]
```

以下情况建议触发更新：

- 文件创建超过 18 个月
- 用户提到“最新指南”“新版规范”
- 论文所引指南明显更新
- 审查时反复暴露手册不完备

更新时不要整篇覆盖；优先补当前缺口最大的章节。

## 8. 共享专项模板与标准

新建或重写共享专项时，不要只复制旧模板。结构标准见 [specialty-manual-standard.md](./specialty-manual-standard.md)。

最低模板如下：

```markdown
# [专业领域]专项

最后更新：YYYY-MM
适用范围：[具体专业描述]
主要参考规范：[规范名称]

## 触发条件
## 适用边界
## 研究类型分流
## 毕业论文场景重点
## 该领域特有的方法学要求
## 核心结局指标与金标准
## 学科语域与常用审查用语
## 报告规范要点
## 高频风险点
## 安全定位建议
## 屏蔽说明
## 与通用框架/其他专项的优先级
## 何时判定为手册不完备
```
