# 强制深审闸门

当论文属于临床干预、随机对照、康复工程、神经工程、脑机接口、神经影像或用户明确要求“更深的科学性 / 学术性检查”时，加载此文件。

这份文件的作用不是增加术语，而是把“多镜头提示”升级成**必须执行的第二阶段深审**。

## 1. 什么时候必须进入深审

只要满足以下任一条件，就不能只做普通快筛：

- 研究主轴是疗效比较、随机分组、假刺激、对照或临床干预
- 题目、结局或论证高度依赖设备、信号处理、脑图、连接图、流程图
- 摘要、正文、表格、图片中对核心结局存在冲突线索
- 用户要求用于送审把关、盲审把关或答辩把关
- 外部专家、导师或其他代理对核心结论有明显分歧

## 2. 两阶段审查

### 第一阶段：快筛

目标是快速识别硬伤和方向。

至少完成：

- 研究身份与样本流程的初步一致性检查
- 统计口径和等级资料处理方式的快速核查
- 伦理、注册、知情同意的存在性检查
- 图号、表号、正文互引的明显错误扫描

### 第二阶段：深审

目标是确认论文真正的可信度瓶颈。

至少完成：

1. 核心结局证据链表
2. 干预与对照矩阵
3. 图片法证核查
4. 工程可复现性矩阵
5. 答辩高风险问题清单

如果环境支持专门 agent，优先并行执行；如果不支持，就按这五项串行做完。

如果某一项因材料缺失、本地环境限制或用户明确缩限而无法完成，必须在 `reviews/评审闭环与放行判断.md` 中写清当前 blocker 和降级理由；没有写清前，不要直接给送审 / 答辩 readiness 或学生执行清单。

## 3. 五个必交付证据

### A. 核心结局证据链表

对每一个核心结局，至少核对：

- 结局名称和层级：主要 / 次要 / 探索性
- 来源工具或评分体系
- 采集时间点
- 评分者或分析者
- 数据类型与统计方法
- 摘要、正文、表格、图片是否一致

高危信号：

- `VFSS / FEES / PAS` 链条打架
- 摘要和正文对同一核心结局方向不同
- 表格与图片展示的并非同一指标或同一统计量

### B. 干预与对照矩阵

至少列出：

- 每组总治疗时间
- 设备治疗时间
- 常规治疗时间
- 额外注意力 / 共干预
- 假刺激是否真正时间匹配
- 是否存在暴露不平衡

高危信号：

- 疗程或单次时长在不同段落冲突
- 常规组和设备组总暴露不同，却仍做强因果归因
- 对照组定义不清，导致无法解释阳性差异来自哪里

### C. 图片法证核查

核心图必须回到真实页面和裁切图核对：

- 图号、图题、图注、正文引用是否一一对应
- 坐标轴顺序、单位、误差线、色标是否正确
- 图中展示的是原始量、统计量还是效应值
- 图形类型是否匹配数据类型

高危信号：

- 横轴反序
- `SSA` 图写成 `PAS分`
- 非参数结果仍画成 `mean ± SD` 柱图
- `t` 值图被写成生理浓度图

### D. 工程可复现性矩阵

对设备或信号类研究，至少核对：

- 型号、通道数、软件版本
- 采样频率、滤波、预处理
- 特征提取窗口、阈值、ROI/通道选择规则
- 归一化方法
- 黑箱部分是否诚实承认不可见

高危信号：

- 只写设备名，不写采样和预处理
- 用绝对幅值直接跨组比较，却没有归一化或局限性说明
- 多通道分析没有校正，也没有诚实降级为探索性

### E. 答辩高风险问题清单

至少准备：

- 最可能被问倒的 `5-8` 个问题
- 每个问题的安全回答框架
- 不可说的越界表述

## 4. 直接升为 P0 的条件

以下情况优先升为 `P0`：

- 样本流程在摘要、方法、结果、图表之间互相矛盾
- 核心结局的来源工具、评分方式或时间点自相矛盾
- 等级资料仍按连续变量主分析，且支撑核心结论
- 干预与对照暴露明显不平衡，却支撑了强疗效结论
- 图片语义错误已经影响结果理解

## 5. 交付时怎么体现

深审结果不要只散落在长文里。至少要在最终交付物中能看见：

- `P0 / P1 / P2` 分级结论
- 哪些问题来自哪一类深审证据
- 哪些外部建议被 `Adopt / Adopt with rewrite / Downgrade / Reject`
- 哪些是当前必须改，哪些只是答辩策略

## 6. 环境降级规则

如果当前环境不能直接看图片、不能联网或不能并行，不要停工，按下面方式降级：

- 不能直接看图：先导出 PDF 页面图和裁切图
- 不能联网：只做本地事实深审，并明确“最新规范未在线核实”
- 不能并行 agent：按 `样本与对照 -> 结局与统计 -> 图像 -> 工程 -> 答辩` 的顺序串行执行

降级的是工具，不是证据标准。
