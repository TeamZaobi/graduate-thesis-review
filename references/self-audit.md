# 交付物自审清单

当综合报告、修改清单、HTML 汇总页、学生版和导师版即将交付时，先跑这份短版主清单。

这份文件查的不是论文本身，而是**我们自己的交付物有没有在关键接缝上出错**。论文终检见 [output-templates.md](./output-templates.md) 第 8 节。

## 核心 16 项

### 1. 版本与真源

1. 是否明确记录了本轮审阅对象、当前版本基线和唯一真源？
2. 是否区分了 `已存在但待重写 / 确实缺失 / 已完成但需回归`，而不是混成一个“未完成”？
3. 模板文件和实填证据是否已经分清，没有把空骨架当成“已完成审查”？

### 2. 专项与边界

4. 当前论文有没有明确记录专项手册状态是 `complete / partial / missing`？
5. 如果是 `partial` 或 `missing`，是否已经生成 `专业手册完备性判断` 和 `专业专项补充说明`？
6. 如果没有原始数据或脚本，是否明确写清本轮是“非复算审查”，没有暗示重跑过模型？

### 3. 引用与证据

7. 报告中的核心数字、图号、表号和原文是否完全一致？
8. 所有关键判断是否都能回到原文、表图、对象层或一手来源，而不是只引用二手转述？
9. 如果给了原子级改写建议，是否都保留了证据锚点，没有偷偷补造事实？

### 4. 分级、放行与同步

10. 如果已经生成执行清单、学生版、导师版或 readiness 判断，是否先写了 `评审闭环与放行判断.md`，并且放行结论与交付物一致？
11. 同一个问题在综合报告、清单、HTML 中的 `P0 / P1 / P2` 级别是否一致？
12. HTML 的问题数量、优先级和卡片内容，是否与清单和综合报告同步？
13. 学生版是否完整保留了所有 `P0`，导师版的总体判断是否与综合报告一致？

### 5. 红线与一致性

14. 交付物里有没有把探索性、观察性或替代终点结果写成确证性结论？
15. 有没有补造盲法、注册号、算法细节、独立评估者或其他原文不存在的事实？
16. 多镜头判断之间是否自相矛盾，尤其是 `stats / figure / writing / defense` 之间？

## 按需加跑的扩展回检

只有命中对应场景时，再补这些扩展检查：

- 深审项目：确认五项第二阶段深审项是否已完成，或未完成项是否已在 `评审闭环与放行判断.md` 中明确写成 blocker / 降级项
- 图表密集项目：确认 HTML 图片、对象层路径和关键图证仍然有效
- 观察性因果推断项目：补查 `time zero / estimand / positivity / ESS / interaction`
- 目录迁移项目：补查旧绝对路径和路径漂移

## 何时跑

- 综合报告、清单和 HTML 全部完成后
- 学生版和导师版拆分完成后
- 任一交付物被二次修改后

如果时间很紧，至少先过完上面的 15 项，再决定是否加跑扩展项。
