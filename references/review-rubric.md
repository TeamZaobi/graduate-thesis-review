# 论文审查细则

当论文审查需要更细的核查框架时，加载此文件。尤其适用于医学、临床、康复、工程、神经科学等交叉型论文。此细则对中文和英文论文都适用，只是最终输出默认按中文使用者的阅读和执行习惯组织。

## 0. 先做研究类型分流

开始详细审查前，先判断它属于哪一类临床研究。

- 干预 / 随机研究
- 观察性研究
- 诊断准确性研究
- 预测模型研究
- 系统综述 / Meta

具体分流规则见 [clinical-study-types.md](./clinical-study-types.md)。

如果论文还明显带有康复治疗、神经工程、脑机接口、神经影像等特征，再继续加载 [rehab-neuroengineering.md](./rehab-neuroengineering.md)。

如果论文主轴是公共卫生、真实世界队列、药物流行病学、目标试验模拟或交互作用分析，再继续加载 [specialty-public-health-causal.md](./specialty-public-health-causal.md)。

如果任务混入了 `Codex`、`Claude Code`、`AntiGrativity` 或其他代理的 transcript、建议、截图、自动生成文档，再继续加载 [agent-tool-adaptation.md](./agent-tool-adaptation.md)。

## 0.2 先过专项手册完备性 gate

开始详细审查前，不要因为已有 `specialty-*.md` 就默认足够。

先回答四个问题：

- 当前论文的专业和亚专业到底是什么
- 当前研究类型是什么
- 当前处在哪个毕业论文阶段（开题、送审前、外审回复、预答辩、正式答辩前、终稿回归）
- 现有专项手册对这篇论文是 `complete / partial / missing`

如果答案是 `partial` 或 `missing`，先补：

- `专业手册完备性判断`
- `专业专项补充说明`

再进入真正的专项深审，不要跳过这一步。

## 0.3 先冻结审阅对象、版本真源和模板状态

开始详细审查前，先回答三个问题：

- 现在到底审哪一个文件、哪一个版本、哪一组补充材料
- 学生或其他代理口中的“已完成/未完成”，和真实文档状态是否一致
- 当前工作区里哪些只是模板文件，哪些已经填入了可回查证据

如果这三件事没搞清，后面的“深审”很容易只是对着旧版本或空骨架做推演。
同时检查 `reviews/review_version_manifest.json` 是否已写明当前 `entry_mode / truth_source / readiness`；如果它仍是 `tainted`，先清 manifest，再继续深审。

## 0.4 先判断结构化资产和接手面是否存在

开始详细审查前，再补查两件事：

- 图、表、引文和资产路径，是不是已经进入对象层，还是仍分散在 Markdown 台账和聊天记录里
- 当前项目如果跨了多个线程、代理或工具，有没有 `process_projection` 作为统一接手面

优先对象层：

1. `objects/figures.json`
2. `objects/tables.json`
3. `objects/citations.json`
4. `objects/assets_manifest.json`

对图件密集项目，再补两个最小判断：

- `objects/figures.json` 中每个图件至少区分 `docx_media` 还是 `shape_rendered`
- `objects/assets_manifest.json` 中每个资产至少区分 `source_kind` 和 `asset_type`，不要把页面渲染图误写成“从源抽图”

如果这些结构化资产缺失，并不等于不能审；但后续要主动收紧边界，避免把“路径记忆”和“线程记忆”误当成稳定证据。

## 0.5 代理来源与证据层级

跨代理协作时，先做这个判断，再进入具体问题审查：

- 哪些材料是原论文、原图、原表、当前版本文件
- 哪些材料是其他代理的判断、摘要、截图或中间产物
- 哪些结论已经被本地文件核实，哪些仍只是高价值线索

固定证据顺序：

1. 论文原始文件和当前工作区文件
2. 从原文件直接导出的文本、页面图、裁切图
3. 官方指南和方法学一手来源
4. 其他代理、导师、外审的意见
5. terminal 截图、转述和二手摘要

低层级材料可以触发核查，但不能直接定案。

## 0.7 复算准入与证据边界

在把问题升级为“结果错误”前，先确认我们有没有资格这么说：

- 是否有原始数据、脚本、结果导出，或至少可追溯的真源表图
- 本轮到底是复算审查，还是 `文本 + 图表 + 锚点` 审查
- 如果没有复算条件，是否已经明确收紧表述，避免让读者误解为“重新跑过模型”

## 0.8 风险分级与外审预测

除了 `P0 / P1 / P2`，对高风险论文建议显式补到 `P3 / P4`：

- `P0`：阻断送审、答辩或研究身份可信度的问题
- `P1`：高概率被外审或答辩专家追问、需要实质性重写的问题
- `P2`：方法与报告规范层的中高压风险，通常在 `P0/P1` 清理后继续被问
- `P3`：清稿、QA、术语、图表注释、目录、格式和交付回归问题
- `P4`：外审/答辩防守增强项，如高压问题口径、benchmark、rebuttal 准备

默认至少给出三个层级的风险预测：

1. 如果按当前版本直接送审，会怎样
2. 如果只清完 `P0`，还会被什么继续追问
3. 到什么阈值才算“相对安全可送审”

## 1. 高风险审查地图

### A. 审阅对象冻结、结果真源与版本漂移

先核对：

- 当前结论到底绑定哪一版论文、哪份补充材料
- 核心数字是否都有唯一真源
- 摘要、结论、图注、表题、HTML 和修改清单里是否残留旧值
- 创建了多少台账文件，其中哪些已经实填，哪些仍是空骨架

这一步不清，就不要急着把零散问题升成 `P0`；先处理版本漂移和真源冲突。

### B. 研究身份与样本流程

核对同一项研究是否在以下位置保持一致：

- 标题与摘要
- 方法中的研究设计表述
- 资格判定、暴露归属、`time zero` 和随访起点
- 样本量估算段
- 招募、排除、脱落流程
- 结果分析集与分母
- 表格、图注、流程图

只要样本数或流程逻辑互相打架，就应直接升为 `P0`。

### C. 干预完整性与对照组可信度

重点检查：

- 每组总治疗时间是否一致
- 对照组到底做了什么，是否定义清楚
- 是否存在额外关注、额外训练或不平衡共干预
- 设备参数、刺激条件、治疗师操作是否可复现
- 盲法是做不到、没做、还是没写清楚

安全表述示例：

- “由于干预形式差异明显，受试者和治疗师盲法不可行”
- “独立评估者盲法未见明确报告”
- “数据分析是否屏蔽分组信息仍需核实”

### D. 结局与统计

重点检查：

- 结局是否真的对应题目和靶点
- 数据类型和检验方法是否匹配
- 是否有主要 / 次要 / 探索性结果层级
- 观察性因果推断论文里，`estimand / interaction scale / competing risk question` 是否被清楚区分
- `DAG / 调整集 / overlap / positivity / truncation / ESS` 是否至少有清楚的判断入口
- 多重比较是处理了，还是至少诚实降格为探索性
- 边缘显著或未显著结果是否被过度发挥
- 正文、表格、图注是否讲的是同一套统计口径

如果等级资料仍写成 `均数±标准差 + t 检验`，通常应直接升为 `P0`。

### E. 图片与表格

必须看真实图，不只看图题。

重点检查：

- 图号是否唯一，是否符合学校编号规则
- 图号、图题、图注、正文引用、实际图片是否一一对应
- 图注内容是否和表格、结果文字一致
- 成对图片的色标是否可比
- 图中展示的量到底是什么
- 关键差异是否被视觉强化出来
- 打印和投屏时是否清楚
- 图像路径和表格定位是否已经沉淀进对象层，而不是只活在手写 Markdown 链接中

高频图像硬伤：

- 两个 `图1`、两个 `图2`
- 正文写“见图1”，实际设备在 `图3` 或 `图4`
- 激活图被写成功能连接图
- `t` 值图被误写成生理信号浓度图
- 连接矩阵铺满全图，却没有任何重点标注

### F. 写作与参考文献

重点检查：

- 摘要、方法、结果、结论是否前后一致
- 标题、研究目的、结局是否真正闭合
- 中英文术语是否稳定
- 机制表述是否明显强于证据
- 引文号、参考文献格式、条目主题是否对应
- 是否缺少近年的关键指南、最佳实践或同类研究
- 文献综述是真的完成了，还是只有章节存在但缺少实质对标和方法学一手来源
- 关键方法句和创新性表述，是否都能回到对应引文，而不是凭印象补写

如果论文已经接近送审，参考文献值得单列检查，因为它修复成本低、被发现概率高。

### G. 伦理、注册、数据追溯与报告规范

重点检查：

- 伦理审批机构与批准号
- 知情同意表述
- 临床注册状态与时间
- 利益冲突、资金来源、数据可得性、软件版本或分析环境说明
- 未注册或晚注册时，论文是否诚实定位为探索性
- CONSORT / TIDieR 这类报告规范里，是否缺了关键项

### H. 主文、补充与附录闭环

当论文依赖补充表、补充图、附录模型或附件时，额外检查：

- 主文是否给出了清晰入口，而不是默认读者自己去找
- 主文、补充和附录的编号、图题、结果口径是否一致
- 是否把关键诊断“藏”在附录里，却在主文和摘要中给出更强结论

### I. 版本回归与项目卫生

当审查产出被多轮修改后，要额外检查：

- 说明文档是否和真实目录一致
- HTML 指标数、锚点、图片路径是否仍同步
- 新改动有没有引入脏字符、错链、旧版本残留
- 清单是否已经膨胀到需要拆出学生版和导师版
- 多线程项目的接手信息是否已经被压进 `process_projection`，还是只能靠聊天回放恢复
- `review_version_manifest.json` 是否已经同步更新 `entry_mode / rebase / dependents / readiness`

## 2. 多镜头提问模板

只启用和论文真正相关的镜头，不要为了“显得全面”而机械堆镜头。

### 流行病学

- 研究身份是否自洽？
- 偏倚结构是否被诚实承认？
- 纳入、排除、脱落是否可追踪？

### 观察性因果推断

- 它到底在回答什么因果问题，估计量有没有说清？
- `time zero`、暴露归属和随访起点是否对齐？
- `IPTW / IPCW / MSM / competing risk` 是真在解决偏倚，还是只是在堆术语？
- 分层分析、乘法交互和加法交互是不是被混成一个结论？
- `DAG / 调整集 / overlap / positivity / 异质性可信度` 有没有被真正审到，而不是只看摘要里的术语

### 统计学

- 检验方法是否匹配数据类型？
- 重复测量和多重比较处理是否站得住？
- 结论是否比数据更强？

### 导师式精修

- 哪些句子必须降级、拆句、补边界，而不是继续润色？
- 这一句到底该绑哪张表、哪条结果、哪篇方法学文献？
- 哪些段落应该迁移，哪些句子根本不该保留？

### 学术写作

- 标题、摘要、方法、结果、结论说的是不是同一件事？
- 中英文术语是否稳定？
- 局限性是真的局限，还是礼节性写几句？

### 医学 / 生物医学工程

- 别的团队能否复现设备与流程？
- 采集、预处理、解码是否有足够透明度？
- 闭源部分是否被诚实承认？

### 康复科学

- 干预靶点是否对得上功能阶段？
- 剂量、频次、治疗师动作是否讲透？
- 对照组是否可信？

### 神经科学

- 任务设计真的能探测你声称的机制吗？
- 激活和连接有没有混写？
- “脑-行为桥接”是真有证据，还是只是想当然？

## 3. 外部建议分流规则

当用户拿来其他 AI、导师、外审、`Codex`、`Claude Code`、`AntiGrativity` 或其他代理的建议时，用下面四类收口：

### Adopt

事实正确，收益高，风险低，直接吸收。

### Adopt with rewrite

方向是对的，但措辞过强、过松、过时，或有方法学边界问题，需要改写后吸收。

### Downgrade

建议本身有价值，但属于 `P1 / P2` 或未来研究，不应被写成当前最高优先级。

### Reject

建议误读原文、补造事实，或采纳后会引入新的问题。

## 4. 红线与安全改写

绝对不要做的事：

- 补造独立评估者
- 没注册却写有注册号
- 把事后重排的结果层级写成预注册主要结局
- 把探索性影像结果写成确证性证明
- 假装自己知道闭源算法细节
- 为图片写入原始生成里没有出现过的单位和量纲

优先使用的安全改写：

- “与靶点更贴近”
- “支持性但非特异性”
- “探索性机制证据”
- “初步证据 / 初步信号”
- “仍需前瞻性验证”
- “应结合以下局限谨慎解释”

## 5. 图片专项核查清单

论文里只要有设备图、柱状图、脑地形图、连接图，就跑这一轮。

1. 确认所有图号唯一。
2. 全文搜索每一个“见图”，核对是否真的指向那张图。
3. 核对图注、表格、正文对通道、时间点、条件的描述是否一致。
4. 核查配对图片的色标能否直接比较。
5. 核查图中展示的是 `t` 值、效应值、HbO2 变化还是别的量。
6. 判断这张图的问题属于硬伤、表达问题，还是可选增强。
7. 明确最佳修法是：
   - 改图注
   - 改正文引用
   - 重绘图片
   - 增加重点标注
   - 只放到未来工作，不在本轮补做

## 6. 三层建议顺序

固定按这个顺序出手：

1. 先修会伤害可信度和送审安全的硬伤
2. 再做高回报的答辩增强
3. 最后给出工作量更大的未来升级路线

不要让第 2 层或第 3 层分散对第 1 层的注意力。
