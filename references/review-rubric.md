# 论文审查细则

当论文审查需要更细的核查框架时，加载此文件。尤其适用于医学、临床、康复、工程、神经科学等交叉型论文。此细则对中文和英文论文都适用，只是最终输出默认按中文使用者的阅读和执行习惯组织。

## 0. 先做研究类型分流

开始详细审查前，先判断它属于哪一类临床研究。

- 干预 / 随机研究
- 观察性研究
- 诊断准确性研究
- 预测模型研究
- 系统综述 / Meta

具体分流规则见 [clinical-study-types.md](./clinical-study-types.md)。

如果论文还明显带有康复治疗、神经工程、脑机接口、神经影像等特征，再继续加载 [rehab-neuroengineering.md](./rehab-neuroengineering.md)。

如果任务混入了 `Codex`、`Claude Code`、`AntiGrativity` 或其他代理的 transcript、建议、截图、自动生成文档，再继续加载 [agent-tool-adaptation.md](./agent-tool-adaptation.md)。

## 0.5 代理来源与证据层级

跨代理协作时，先做这个判断，再进入具体问题审查：

- 哪些材料是原论文、原图、原表、当前版本文件
- 哪些材料是其他代理的判断、摘要、截图或中间产物
- 哪些结论已经被本地文件核实，哪些仍只是高价值线索

固定证据顺序：

1. 论文原始文件和当前工作区文件
2. 从原文件直接导出的文本、页面图、裁切图
3. 官方指南和方法学一手来源
4. 其他代理、导师、外审的意见
5. terminal 截图、转述和二手摘要

低层级材料可以触发核查，但不能直接定案。

## 1. 高风险审查地图

### A. 研究身份与样本流程

核对同一项研究是否在以下位置保持一致：

- 标题与摘要
- 方法中的研究设计表述
- 样本量估算段
- 招募、排除、脱落流程
- 结果分析集与分母
- 表格、图注、流程图

只要样本数或流程逻辑互相打架，就应直接升为 `P0`。

### B. 干预完整性与对照组可信度

重点检查：

- 每组总治疗时间是否一致
- 对照组到底做了什么，是否定义清楚
- 是否存在额外关注、额外训练或不平衡共干预
- 设备参数、刺激条件、治疗师操作是否可复现
- 盲法是做不到、没做、还是没写清楚

安全表述示例：

- “由于干预形式差异明显，受试者和治疗师盲法不可行”
- “独立评估者盲法未见明确报告”
- “数据分析是否屏蔽分组信息仍需核实”

### C. 结局与统计

重点检查：

- 结局是否真的对应题目和靶点
- 数据类型和检验方法是否匹配
- 是否有主要 / 次要 / 探索性结果层级
- 多重比较是处理了，还是至少诚实降格为探索性
- 边缘显著或未显著结果是否被过度发挥
- 正文、表格、图注是否讲的是同一套统计口径

如果等级资料仍写成 `均数±标准差 + t 检验`，通常应直接升为 `P0`。

### D. 图片与表格

必须看真实图，不只看图题。

重点检查：

- 图号是否唯一，是否符合学校编号规则
- 图号、图题、图注、正文引用、实际图片是否一一对应
- 图注内容是否和表格、结果文字一致
- 成对图片的色标是否可比
- 图中展示的量到底是什么
- 关键差异是否被视觉强化出来
- 打印和投屏时是否清楚

高频图像硬伤：

- 两个 `图1`、两个 `图2`
- 正文写“见图1”，实际设备在 `图3` 或 `图4`
- 激活图被写成功能连接图
- `t` 值图被误写成生理信号浓度图
- 连接矩阵铺满全图，却没有任何重点标注

### E. 写作与参考文献

重点检查：

- 摘要、方法、结果、结论是否前后一致
- 标题、研究目的、结局是否真正闭合
- 中英文术语是否稳定
- 机制表述是否明显强于证据
- 引文号、参考文献格式、条目主题是否对应
- 是否缺少近年的关键指南、最佳实践或同类研究

如果论文已经接近送审，参考文献值得单列检查，因为它修复成本低、被发现概率高。

### F. 伦理、注册与报告规范

重点检查：

- 伦理审批机构与批准号
- 知情同意表述
- 临床注册状态与时间
- 未注册或晚注册时，论文是否诚实定位为探索性
- CONSORT / TIDieR 这类报告规范里，是否缺了关键项

### G. 版本回归与项目卫生

当审查产出被多轮修改后，要额外检查：

- 说明文档是否和真实目录一致
- HTML 指标数、锚点、图片路径是否仍同步
- 新改动有没有引入脏字符、错链、旧版本残留
- 清单是否已经膨胀到需要拆出学生版和导师版

## 2. 多镜头提问模板

只启用和论文真正相关的镜头，不要为了“显得全面”而机械堆镜头。

### 流行病学

- 研究身份是否自洽？
- 偏倚结构是否被诚实承认？
- 纳入、排除、脱落是否可追踪？

### 统计学

- 检验方法是否匹配数据类型？
- 重复测量和多重比较处理是否站得住？
- 结论是否比数据更强？

### 学术写作

- 标题、摘要、方法、结果、结论说的是不是同一件事？
- 中英文术语是否稳定？
- 局限性是真的局限，还是礼节性写几句？

### 医学 / 生物医学工程

- 别的团队能否复现设备与流程？
- 采集、预处理、解码是否有足够透明度？
- 闭源部分是否被诚实承认？

### 康复科学

- 干预靶点是否对得上功能阶段？
- 剂量、频次、治疗师动作是否讲透？
- 对照组是否可信？

### 神经科学

- 任务设计真的能探测你声称的机制吗？
- 激活和连接有没有混写？
- “脑-行为桥接”是真有证据，还是只是想当然？

## 3. 外部建议分流规则

当用户拿来其他 AI、导师、外审、`Codex`、`Claude Code`、`AntiGrativity` 或其他代理的建议时，用下面四类收口：

### Adopt

事实正确，收益高，风险低，直接吸收。

### Adopt with rewrite

方向是对的，但措辞过强、过松、过时，或有方法学边界问题，需要改写后吸收。

### Downgrade

建议本身有价值，但属于 `P1 / P2` 或未来研究，不应被写成当前最高优先级。

### Reject

建议误读原文、补造事实，或采纳后会引入新的问题。

## 4. 红线与安全改写

绝对不要做的事：

- 补造独立评估者
- 没注册却写有注册号
- 把事后重排的结果层级写成预注册主要结局
- 把探索性影像结果写成确证性证明
- 假装自己知道闭源算法细节
- 为图片写入原始生成里没有出现过的单位和量纲

优先使用的安全改写：

- “与靶点更贴近”
- “支持性但非特异性”
- “探索性机制证据”
- “初步证据 / 初步信号”
- “仍需前瞻性验证”
- “应结合以下局限谨慎解释”

## 5. 图片专项核查清单

论文里只要有设备图、柱状图、脑地形图、连接图，就跑这一轮。

1. 确认所有图号唯一。
2. 全文搜索每一个“见图”，核对是否真的指向那张图。
3. 核对图注、表格、正文对通道、时间点、条件的描述是否一致。
4. 核查配对图片的色标能否直接比较。
5. 核查图中展示的是 `t` 值、效应值、HbO2 变化还是别的量。
6. 判断这张图的问题属于硬伤、表达问题，还是可选增强。
7. 明确最佳修法是：
   - 改图注
   - 改正文引用
   - 重绘图片
   - 增加重点标注
   - 只放到未来工作，不在本轮补做

## 6. 三层建议顺序

固定按这个顺序出手：

1. 先修会伤害可信度和送审安全的硬伤
2. 再做高回报的答辩增强
3. 最后给出工作量更大的未来升级路线

不要让第 2 层或第 3 层分散对第 1 层的注意力。
