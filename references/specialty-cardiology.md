# 心血管专项

最后更新：2026-03
适用范围：心血管内科、心脏外科、血管外科、心脏康复（以心血管问题为主轴）
主要参考规范：ACC/AHA 指南、ESC 指南、CONSORT 2010、SPIRIT 2013

## 触发条件

论文涉及以下任一内容时加载：

- 疾病：冠心病、心肌梗死、心力衰竭、心律失常、高血压、心脏瓣膜病、主动脉疾病、外周血管病
- 干预：PCI、CABG、消融、起搏器、TAVR、药物治疗（抗凝、抗血小板、他汀、ACEI/ARB/ARNI）
- 结局：MACE、心血管死亡、再住院、LVEF、BNP/NT-proBNP、6分钟步行距离（心脏康复语境）
- 影像：超声心动图、冠脉造影、CTA、心脏MRI、核素显像

## 该领域特有的方法学要求

### 终点事件定义

心血管研究的结局定义高度标准化，必须核查：

- MACE（主要不良心血管事件）的具体构成是否明确写出（不同研究定义不同）
- 心血管死亡 vs 全因死亡是否区分
- 心肌梗死的诊断标准（第四版通用定义：肌钙蛋白 + 症状/心电图/影像）
- 心衰住院的定义是否有具体标准（不能只写"因心衰住院"）

**P0 风险**：MACE 定义模糊，或不同段落构成不一致。

### 随访时间与事件率

- 心血管硬终点研究通常需要较长随访（≥6个月，多数≥1年）
- 短随访研究宣称硬终点结论需特别谨慎
- 事件率过低（<5%）时，样本量估算依据需严格核查

### 基线均衡性

- 心血管研究对基线特征要求严格：年龄、性别、LVEF、用药史、合并症（糖尿病、肾功能、既往心梗）
- 随机化后基线不均衡需在分析中调整，不能忽视

### 药物治疗的背景治疗

- 两组背景治疗（指南推荐用药）是否一致
- 新干预叠加在标准治疗上，还是替代标准治疗，需明确

## 核心结局指标与金标准

| 结局类型 | 金标准/推荐指标 |
|---|---|
| 心功能 | LVEF（超声心动图，Simpson法）、NYHA分级 |
| 心衰标志物 | NT-proBNP / BNP |
| 运动耐量 | 6分钟步行距离、心肺运动试验（VO₂max） |
| 冠脉病变 | 冠脉造影（FFR辅助）、CTA |
| 心肌损伤 | 高敏肌钙蛋白（hsTnI/hsTnT） |
| 生活质量 | KCCQ（心衰）、SAQ（冠心病）、SF-36 |
| 硬终点 | 全因死亡、心血管死亡、非致死性心梗、非致死性卒中 |

## 报告规范要点

### CONSORT（干预研究）

- 随机序列生成方法（不能只写"随机分组"）
- 分配隐藏方案
- 盲法：心血管研究中开放标签很常见，需诚实申报，不能伪装成盲法
- 样本量估算：基于主要结局的事件率和预期差异

### 观察性研究（STROBE）

- 暴露定义（如"他汀使用"需定义剂量、时长、依从性）
- 混杂因素控制（心血管研究混杂因素多，倾向评分匹配常见）
- 随访缺失和竞争风险处理

---

## 高频风险点

**P0（硬伤）**
- MACE 定义在摘要、方法、结果中不一致
- 主要结局未预先定义，事后挑选阳性指标
- 样本量估算基于不合理的事件率假设（如假设对照组事件率远高于文献报道）
- 短随访（<3个月）却宣称降低硬终点事件

**P1（会被追问）**
- 背景治疗两组不均衡但未调整
- 只报 LVEF 变化，不报临床结局
- 亚组分析未预先注册，却做确定性宣称
- 开放标签研究宣称"盲法评估"但评估者知晓分组

**P2（规范加固）**
- 未报告置信区间（只报 P 值）
- 超声心动图测量者间一致性未报告
- 随访缺失率 >10% 但未做敏感性分析

---

## 安全定位建议

- 单中心、小样本、短随访：定位为"探索性研究"或"假设生成研究"
- 替代终点（如 LVEF 改善）：明确说明"替代终点改善，硬终点获益尚需大规模研究验证"
- 观察性研究：避免因果语气，用"与……相关"而非"……导致"

## 屏蔽说明

激活此文件时，以下通用检查不适用或需调整：

- **康复剂量三要素**（每次时长/每周频次/总周数）：仅在心脏康复研究中适用，纯介入/药物研究不适用
- **fNIRS/EEG 信号链检查**：不适用
- **康复生态效度**：不适用于手术或药物研究
- **神经工程设备透明度**：不适用
