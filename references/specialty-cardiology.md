# 心血管专项

最后更新：2026-03
适用范围：心血管内科、心脏外科、血管外科、心脏康复（以心血管问题为主轴）
主要参考规范：ACC/AHA 指南、ESC 指南、CONSORT 2010、SPIRIT 2013

## 触发条件

论文涉及以下任一内容时加载：

- 疾病：冠心病、心肌梗死、心力衰竭、心律失常、高血压、心脏瓣膜病、主动脉疾病、外周血管病
- 干预：PCI、CABG、消融、起搏器、TAVR、药物治疗（抗凝、抗血小板、他汀、ACEI/ARB/ARNI）
- 结局：MACE、心血管死亡、再住院、LVEF、BNP/NT-proBNP、6分钟步行距离（心脏康复语境）
- 影像：超声心动图、冠脉造影、CTA、心脏MRI、核素显像

## 适用边界

这份手册优先覆盖：

- 以心血管疾病诊疗、事件终点或心功能改善为主轴的学位论文
- 心内、心外、血管外科和以心血管疾病为主轴的心脏康复

默认不直接覆盖：

- 纯康复工程或神经工程论文
- 纯公共卫生因果推断论文，即使疾病是心血管，也应与观察性因果专项并行
- 只做通用运动康复、但并非心血管疾病主线的论文

## 研究类型分流

- `RCT / 干预研究`：优先看主要终点、背景治疗、随机/隐藏、事件率与随访时长
- `观察性研究`：优先看暴露定义、混杂控制、删失和竞争风险
- `手术/介入比较`：重点看术式定义、围术期管理、并发症和时间窗口
- `心脏康复研究`：额外看康复剂量、依从性和运动耐量结局

## 毕业论文场景重点

- 开题：主要终点、随访时长和样本量假设是否现实
- 送审前：MACE、死亡、再住院、LVEF、背景治疗等定义是否已经统一
- 外审回复：优先回应“终点定义模糊”“短随访却讲硬终点”“背景治疗不均衡”
- 预答辩 / 正式答辩前：必须准备“替代终点 vs 硬终点”的安全口径

## 该领域特有的方法学要求

### 终点事件定义

心血管研究的结局定义高度标准化，必须核查：

- MACE（主要不良心血管事件）的具体构成是否明确写出（不同研究定义不同）
- 心血管死亡 vs 全因死亡是否区分
- 心肌梗死的诊断标准（第四版通用定义：肌钙蛋白 + 症状/心电图/影像）
- 心衰住院的定义是否有具体标准（不能只写"因心衰住院"）

**P0 风险**：MACE 定义模糊，或不同段落构成不一致。

### 随访时间与事件率

- 心血管硬终点研究通常需要较长随访（≥6个月，多数≥1年）
- 短随访研究宣称硬终点结论需特别谨慎
- 事件率过低（<5%）时，样本量估算依据需严格核查

### 基线均衡性

- 心血管研究对基线特征要求严格：年龄、性别、LVEF、用药史、合并症（糖尿病、肾功能、既往心梗）
- 随机化后基线不均衡需在分析中调整，不能忽视

### 药物治疗的背景治疗

- 两组背景治疗（指南推荐用药）是否一致
- 新干预叠加在标准治疗上，还是替代标准治疗，需明确

## 核心结局指标与金标准

| 结局类型 | 金标准/推荐指标 |
|---|---|
| 心功能 | LVEF（超声心动图，Simpson法）、NYHA分级 |
| 心衰标志物 | NT-proBNP / BNP |
| 运动耐量 | 6分钟步行距离、心肺运动试验（VO₂max） |
| 冠脉病变 | 冠脉造影（FFR辅助）、CTA |
| 心肌损伤 | 高敏肌钙蛋白（hsTnI/hsTnT） |
| 生活质量 | KCCQ（心衰）、SAQ（冠心病）、SF-36 |
| 硬终点 | 全因死亡、心血管死亡、非致死性心梗、非致死性卒中 |

## 学科语域与常用审查用语

- 推荐用语：`主要结局`、`次要结局`、`硬终点`、`背景治疗`、`绝对风险`、`临床获益`、`统计不确定性`
- 不推荐直接进入对外交付物的用语：`闭环`、`证据链打通`、`工程回归`、`原子级`
- 建议替换：
  - “结论过强” → “当前证据不足以支持降低硬终点风险的表述”
  - “路径漂移” → “主要结局定义在摘要、方法与结果之间不一致”
  - “闭环不足” → “基线、干预、结局与随访信息尚未形成完整论证”
- 给导师和学生的页面标题，优先用“主要结局一致性核查”“背景治疗平衡性说明”“随访与事件定义说明”，少用跨学科工程隐喻

## 报告规范要点

### CONSORT（干预研究）

- 随机序列生成方法（不能只写"随机分组"）
- 分配隐藏方案
- 盲法：心血管研究中开放标签很常见，需诚实申报，不能伪装成盲法
- 样本量估算：基于主要结局的事件率和预期差异

### 观察性研究（STROBE）

- 暴露定义（如"他汀使用"需定义剂量、时长、依从性）
- 混杂因素控制（心血管研究混杂因素多，倾向评分匹配常见）
- 随访缺失和竞争风险处理

## 高频风险点

**P0（硬伤）**
- MACE 定义在摘要、方法、结果中不一致
- 主要结局未预先定义，事后挑选阳性指标
- 样本量估算基于不合理的事件率假设（如假设对照组事件率远高于文献报道）
- 短随访（<3个月）却宣称降低硬终点事件

**P1（会被追问）**
- 背景治疗两组不均衡但未调整
- 只报 LVEF 变化，不报临床结局
- 亚组分析未预先注册，却做确定性宣称
- 开放标签研究宣称"盲法评估"但评估者知晓分组

**P2（规范加固）**
- 未报告置信区间（只报 P 值）
- 超声心动图测量者间一致性未报告
- 随访缺失率 >10% 但未做敏感性分析

## 安全定位建议

- 单中心、小样本、短随访：定位为"探索性研究"或"假设生成研究"
- 替代终点（如 LVEF 改善）：明确说明"替代终点改善，硬终点获益尚需大规模研究验证"
- 观察性研究：避免因果语气，用"与……相关"而非"……导致"

## 屏蔽说明

激活此文件时，以下通用检查不适用或需调整：

- **康复剂量三要素**（每次时长/每周频次/总周数）：仅在心脏康复研究中适用，纯介入/药物研究不适用
- **fNIRS/EEG 信号链检查**：不适用
- **康复生态效度**：不适用于手术或药物研究
- **神经工程设备透明度**：不适用

## 与通用框架/其他专项的优先级

- 与 `clinical-study-types.md` 同时加载时，先按研究类型分流，再由本专项细化心血管终点和背景治疗要求
- 与公共卫生/观察性因果专项同时加载时：
  - 若主轴是真实世界比较、药物流行病学、因果识别，本专项只补心血管终点定义
  - 因果识别和加权诊断优先由观察性因果专项负责
- 与康复专项同时加载时，仅在“心脏康复”语境下保留康复剂量检查，其他心血管研究以本专项为主

## 何时判定为手册不完备

以下情况出现时，应把本手册判为 `partial` 或 `missing`：

- 论文主轴其实是复杂真实世界因果推断，但当前手册不足以支持 time zero、positivity、竞争风险等判断
- 论文属于儿童心脏病、先心病、先天性血管病等特殊亚专科，需补更细规范
- 论文 heavily 依赖器械、影像或康复工程细节，而本手册只够覆盖临床终点
- 当前任务要求外审回复或答辩场景的学校规则，而非单纯专业方法学判断
