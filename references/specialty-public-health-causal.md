# 公共卫生与观察性因果推断专项

最后更新：2026-04
适用范围：公共卫生、临床流行病学、真实世界队列、药物流行病学、目标试验模拟、病例对照和以因果推断为主轴的学位论文
主要参考规范：STROBE、TARGET Statement、目标试验模拟框架、倾向评分加权最佳实践、交互作用报告建议

## 触发条件

出现以下任一特征时，加载此专项文件：

- `cohort / retrospective / prospective / case-control / registry / EHR / real-world`
- `target trial emulation / new-user / active-comparator`
- `IPTW / IPCW / MSM / weighted Cox / Aalen-Johansen / Fine-Gray`
- `effect modification / interaction / RERI / AP / SI`
- 公共卫生学院、流行病学、药物流行病学、临床流行病学、真实世界证据等表述

## 适用边界

这份手册优先覆盖：

- 以观察性比较、真实世界证据或因果推断为主轴的学位论文
- 目标试验模拟、倾向评分加权、竞争风险、效应修饰等方法学重心明确的项目

默认不直接覆盖：

- 传统 `RCT` 或实验性干预论文
- 纯描述性公共卫生调查，不以因果识别为主轴
- 纯算法预测论文，若无明确因果问题

## 研究类型分流

- `回顾性 / 前瞻性队列`：优先看 time zero、暴露归属、删失和混杂控制
- `病例对照`：优先看病例与对照选择、暴露测量和时间顺序
- `目标试验模拟`：额外看 `eligibility / strategy / assignment / follow-up / analysis`
- `药物流行病学`：额外看 new-user、active-comparator、停药/换药和依从性
- `异质性 / 交互作用分析`：额外看尺度、预设性、多重比较和可信度

## 毕业论文场景重点

- 开题：因果问题、估计量和暴露/结局时间轴是否讲清
- 送审前：正文、补充和附录的诊断材料是否闭环，不能把关键诊断藏在补充里
- 外审回复：优先回应“不是 target trial”“加权诊断不足”“交互作用写过强”
- 预答辩 / 正式答辩前：必须准备“相关 vs 因果”“探索性异质性”的安全口径

## 该领域特有的方法学要求

### A. 先说清楚因果问题与估计量

- 是在回答描述性关联、平均处理效应、策略比较，还是效应修饰问题
- `ITT / PP / total effect / direct effect / subgroup heterogeneity` 这些词不能混写
- 如果是目标试验模拟，至少把 `eligibility / strategy / assignment / time zero / follow-up / outcome / analysis` 映射清楚
- 复杂论文建议单独列一张 `estimand register` 或 `目标试验协议映射表`，避免摘要、方法、讨论各说各话

### B. DAG、变量角色与调整集要能讲清楚

- 至少区分 `混杂因素 / 基线风险 / 中介 / 碰撞变量 / 代理变量 / 时间变化协变量`
- 调整集应能从 `DAG`、临床逻辑或预先方法学依据中解释出来
- 不能一边说“按因果图选变量”，一边又把明显的后果变量或碰撞变量塞进模型
- 如果没有正式 `DAG`，至少要有文字版偏倚路径说明；否则就不要把模型包装成完整因果识别

### C. 资格判定、暴露归属与随访起点必须对齐

- `time zero` 不清，是这一类论文最常见的结构性硬伤
- `new-user` 需要有可执行定义，而不是口头声明
- 如果随访开始晚于暴露归属，优先排查 `immortal time bias`
- 如果 `eligibility / treatment assignment / start of follow-up` 任一缺口太大，应主动把“目标试验模拟”降级为“观察性队列比较”

### D. 混杂控制不能只报“做了加权”

- 至少交代协变量池、建模逻辑、平衡诊断和极端权重处理
- `Love plot / SMD / ESS / CV / truncation / positivity` 是常见最低诊断集合
- 不能把“加权后平衡改善”写成“已等同随机化”
- 只给 `SMD < 0.1` 不够；还应交代重叠性、有效样本量和极端权重对结论稳定性的影响
- 如果主要诊断都躲在补充材料里，主文至少要给清晰入口和一句方法学判断

### E. 竞争风险和绝对风险要分清问题类型

- `CS-Cox` 和 `Fine-Gray` 回答的问题不同，不能混写成同一个“真实风险”
- 如果论文强调临床绝对获益，优先看 `CIF / risk difference / cumulative incidence`
- 只报相对风险、不报绝对风险，通常会削弱公共卫生解释力
- 若同时报告 `HR / CIF / RD / RMST`，要明确每个量回答的具体问题，不能揉成一个“总体有效”

### F. 交互作用必须说明尺度，并评估异质性可信度

- 分层分析、乘法交互、加法交互不是一回事
- `RERI / AP / SI` 的解释边界要写清
- 若以 `HR` 近似 `RR` 计算加法交互，要主动交代近似前提与局限
- 异质性结论至少要追问：是否预设、分层样本量是否足够、多重比较是否膨胀、是否有临床或生物学合理性
- 不能仅凭一项交互 `P` 值就把结果写成“某亚组显著获益”

### G. 敏感性分析要对应偏倚路径，不是越多越好

- 每一种主要偏倚，都应能对应到一项有针对性的敏感性分析或限制性分析
- `Landmark / 妊娠删失 / E-value / 换模型` 各自解决的问题要说清
- “做了很多敏感性分析”不等于“主要偏倚已经被充分解决”
- 如果关键偏倚没有对应分析，不能靠堆附录或堆术语掩盖

### H. 主文、补充与附录要闭环

- 平衡诊断、权重分布、附加模型、补充图表如果放在附录，主文必须给入口和一句结论性解释
- 正文、补充材料和摘要引用的关键数字必须来自同一真源
- 如果补充材料编号、图表入口或结果口径漂移，优先升为结构性问题，而不是简单格式问题

## 核心结局指标与金标准

这一类论文没有统一的“临床金标准”单一模板，重点是：

- 暴露定义是否稳定、可复现、与临床决策点一致
- 结局定义是否可追踪、时间戳是否可信
- 竞争事件、删失规则、行政截止是否明确

如果论文涉及肝病、HBV、HCC 等场景，额外关注：

- 基线肝硬化严重程度
- 既往抗病毒史与洗脱期定义
- 监测强度差异带来的检测偏倚
- 饮酒、代谢共病、家族史等关键混杂

## 学科语域与常用审查用语

- 推荐用语：`因果问题`、`估计量`、`混杂控制`、`平衡诊断`、`竞争风险`、`绝对风险`、`效应修饰`
- 不推荐直接进入对外交付物的用语：`闭环`、`链路打通`、`上游/下游`、`漂移`、`收口`、`原子级`
- 建议替换：
  - “证据链不足” → “识别假设、诊断结果与结论解释之间对应关系不清”
  - “结果漂移” → “摘要、正文与补充材料的定义或数值不一致”
  - “闭环不足” → “偏倚路径、诊断结果与结论降级之间衔接不清”
- 页面标题和问题标签优先使用“目标试验协议映射表”“平衡诊断与权重分布核查”“交互作用与异质性说明”，不要把项目管理或工程排障话术直接带入公卫成品

## 报告规范要点

- 观察性研究基线遵循 `STROBE`
- 目标试验模拟额外关注 `TARGET Statement`
- 如涉及药物比较，明确 `new-user / active-comparator / adherence / switching / censoring`
- 敏感性分析应服务于主偏倚路径，而不是泛泛罗列
- 如报告异质性，建议补一张“异质性可信度卡”或在讨论中明确说明其探索性边界
- 如条件允许，补一张 `目标试验与因果识别审计表`，把方法学 gate 从口头判断变成可回查清单

## 高频风险点

**P0（硬伤）**

- 口头上是 `target trial`，文本上仍是普通回顾性队列
- `time zero`、资格判定和处方定义错位
- 写了 `IPTW / MSM`，却没有平衡或正值性诊断
- 把观察性比较写成“证明某治疗更优”

**P1（会被追问）**

- 把分层结果、交互项和加法交互混成一个“性别差异”结论
- 只看 `P` 值，不交代效应量、绝对风险或不确定性
- 把大量补充诊断藏在附录，却在正文和摘要中直接给出确定性结论

**P2（规范加固）**

- 用敏感性分析的数量代替对主要偏倚路径的解释

## 安全定位建议

- “真实世界观察性比较研究”
- “目标试验模拟框架下的因果推断尝试”
- “结果提示可能存在异质性，但仍需更高质量数据进一步验证”
- “当前证据支持分层风险评估，不直接支持个体化处方决策”

## 屏蔽说明

激活此文件时：

- 不强行套用 `RCT` 的假刺激、暴露时间匹配或盲法申报要求
- 不默认要求康复剂量三要素或设备信号链检查
- 重点转向估计量、偏倚路径、权重诊断、竞争风险和交互作用解释

## 与通用框架/其他专项的优先级

- 与 `clinical-study-types.md` 同时加载时，本专项负责观察性因果识别的专门 gate，通用文件只做类型分流
- 与心血管、肿瘤、肝病等专病专项同时加载时，专病专项负责结局定义与临床语境，本专项负责识别逻辑和分析边界
- 与写作或答辩专项同时加载时，凡涉及因果语气、异质性语气和交互解释，优先以本专项的安全边界为准

## 何时判定为手册不完备

以下情况出现时，应把本手册判为 `partial` 或 `missing`：

- 论文主轴不是因果识别，而是纯诊断、预测或机器学习
- 当前论文依赖本手册未覆盖的专病领域规范，导致结局和暴露定义无法稳住
- 论文进入学校送审/答辩场景，需要额外的毕业论文阶段规则
- 论文涉及本手册未覆盖的新型估计量、复杂多状态模型或更细的领域争议，需要补专门场景说明
