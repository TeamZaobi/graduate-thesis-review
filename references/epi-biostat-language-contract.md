# 流行病学与生物统计学语言合同

当输出导师修改建议、学生执行清单、导师摘要或答辩口径时，加载此文件。

目标不是让所有论文都写成流调教材，而是要求导师建议先经过流行病学与生物统计学语言校准，再进入专业语境。

## 1. 双中轴

### 流行病学轴

负责回答：

- 研究到底在回答什么问题
- 比较基础是否成立
- 偏倚结构和解释边界在哪里
- 外部效度是否被过度扩张

### 生物统计学轴

负责回答：

- 估计对象是什么
- 不确定性有多大
- 数据类型与模型是否匹配
- 结果表达是否超出统计支持

## 2. 所有导师建议必须显式携带的字段

- `epi_basis`
- `stats_basis`
- `claim_boundary`
- `mentor_action`

## 3. 推荐句式

1. `流调层面`
   - 当前研究设计/比较框架只能支持……
2. `统计层面`
   - 当前估计和不确定性只能支持……
3. `结论边界`
   - 因此当前不宜写成……，最多可表述为……
4. `导师动作`
   - 建议优先……
5. `验证动作`
   - 修改后需回查……

## 4. 推荐替换

| 不建议 | 建议替换 |
|---|---|
| 结论太强 | 结论强度超出了当前研究设计与估计精度支持的范围 |
| 证据链不够 | 现有证据不足以支撑当前层级的推断 |
| 机制写大了 | 当前测量更支持代理指标解释，不足以支撑机制推断 |
| 结果不稳 | 估计精度有限，稳健性证据不足 |
| 对照不太行 | 当前比较框架不足以支持明确归因 |

## 5. Claim Ceiling 先于措辞润色

所有导师建议都先回答一个问题：

> 当前这句话最多可以说到什么强度？

`claim_boundary` 必须先由流调/生统语言决定，再允许进入专业和角色投影。

## 6. 禁止事项

- 不用纯经验性语言替代方法学判断
- 不绕过不确定性直接给确定性措辞
- 不让专业术语覆盖掉流调/生统上已经成立的边界
