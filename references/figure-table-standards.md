# 学术统计图表规范

当论文包含统计结果图、机制图、临床表格、脑地形图、连接图或答辩 PPT 图表时，加载此文件。

本文件不是“美化指南”，而是面向学术论文和答辩场景的务实规则，重点解决：

- 什么数据该用什么图
- 什么结果不该硬画图
- 图注、表注、误差线、统计量应该怎么写
- 医学和学位论文里最常见的图表误区

## 1. 总原则

### A. 一图一结论

每张图都要回答一个明确问题。

不要做这种图：

- 什么都想讲
- 图上有很多元素，但看不出作者到底想证明什么
- 只是把统计软件默认输出粘进去

### B. 图只有在比表更清楚时才值得画

如果一张图不能比表格更快地传递信息，就不要为了“显得丰富”硬画图。

优先场景：

- 展示分布
- 展示个体变化
- 展示前后趋势
- 展示组间模式差异
- 展示空间或网络结构

不优先场景：

- 只是罗列均值和 `P` 值
- 只是重复表格里已经一目了然的数据

### C. 论文图和答辩图分开处理

论文图重完整性，答辩图重一眼看懂。

- 论文图：信息完整、图注完整、可追溯
- 答辩图：元素更少、字号更大、重点更强、圈注更明显

不要把论文整页图表原样搬到 PPT。

## 2. 图表类型选择规则

### A. 小样本连续数据

如果样本量较小，优先展示个体数据，不要默认用纯柱状图。

优先级建议：

1. 配对连线图
2. 散点叠加图
3. 箱线图或 violin + 点
4. 最后才是均值柱状图

适用场景：

- 治疗前后
- 每组 `n` 较小
- 评委容易质疑“是不是被少数极端值带出来的差异”

### B. 等级资料 / 非参数结果

不要继续沿用 `mean ± SD + bar chart` 这种默认输出。

优先：

- 排序散点图
- 配对等级变化图
- 中位数 + 四分位信息
- 表格直接呈现频数、等级变化

### C. 组间比较图

如果主要目的是比较两组或多组，优先考虑：

- 点图（dot plot）
- 横向点图
- 配对变化图

谨慎使用：

- 宽而拥挤的条形图
- 图例复杂、颜色过多的并列柱状图

### D. 相关性图

只有在真正想展示“脑-行为桥接”或变量关联时才用。

规则：

- 每个点对应一个个体
- 轴含义明确
- 不要只画回归线不画点
- 样本极小时应谨慎解释

### E. 空间 / 脑成像图

适用于：

- 脑激活
- ROI 比较
- 通道显著性
- 功能连接

必须补充：

- 方向标记（如 `L/R`）
- 色标含义
- 比较条件
- 阈值或校正方式
- 关键区域或连接的视觉引导

## 3. 医学论文里最常见的图表问题

### A. 默认柱状图泛滥

高频误区：

- 小样本还用 `mean ± SD` 柱状图
- 柱状图把个体差异全部藏掉
- 非参数结果仍画成连续数据柱图

### B. 同一数据三重重复

不要同时：

- 正文逐条写
- 表格完整列
- 图里再完整重复一遍

三者应分工：

- 正文：讲结论
- 表格：给精确数据
- 图：给模式和直观比较

### C. 图注不完整

高频缺口：

- 不写误差线是什么
- 不写比较条件
- 不写统计阈值
- 不写色标含义
- 缩写不解释

### D. 图比表还难读

包括：

- 元素太多
- 字太小
- 一页塞图加表
- 颜色太杂
- 图例过长

## 4. 图注和表注最小标准

### 图注至少要说明

1. 图展示的对象和比较条件
2. 统计量或色标代表什么
3. 误差线代表 `SD`、`SEM` 还是别的
4. 显著性标记规则
5. 缩写释义

### 表注至少要说明

1. 变量表达方式（如均值±标准差、中位数[四分位数]、n[%]）
2. 统计方法
3. 缩写释义
4. 如果有校正或特殊处理，要写明

## 5. 统计符号与报告规则

优先遵循这些底线：

- 尽量给精确 `P` 值，而不是只写 `P<0.05`
- 合理补充效应量和 `95% CI`
- 小数位数统一
- 同一类型结果用同一表达风格

不要出现：

- 文中写非参数，图表却沿用参数式呈现
- 图里一个写 `p<0.05`，表里另一个写 `P=0.047`
- 误差线含义前后不一致

## 6. 配色与可读性

### A. 不要只靠颜色编码

同一信息最好同时用：

- 颜色
- 形状
- 线型
- 标注

避免红绿对撞作为唯一编码方式。

### B. 色标必须可解释

尤其对脑激活图和热图：

- 明确色标展示的是哪种量
- 同类比较图尽量统一上下限
- 如果不能统一，图注必须明确“颜色深浅不可直接横向比较”

### C. 远距离阅读友好

答辩图尤其要满足：

- 轴标题清晰
- 字号足够大
- 图例不挤在角落
- 重点有圈注，不靠观众自己找

## 7. 明确不推荐的做法

- 三维柱状图
- 为了“高级”使用复杂渐变、阴影、玻璃拟态
- 一页塞满图和表
- 默认导出后完全不加工
- 只在图里放星号，不解释星号含义
- 把不可比色标的图直接拿来比颜色深浅
- 用图去掩盖表格和正文中的统计口径问题

## 8. 针对当前 Skill 的务实升级动作

当论文图表需要提升时，优先建议：

1. 补受试者流程图
2. 补机制概念图
3. 小样本临床结果改成个体图
4. 给脑激活图和连接图做重点标注
5. 统一图注、表注、误差线和统计符号
6. 把论文图和答辩图分开准备

对以下动作保持谨慎：

- 临时新跑相关性分析
- 临时新做差值脑图
- 临时跨研究做复杂效应量图
- 为了“更好看”而重做所有图

优先原则始终是：先让图表更准确、更清楚，再考虑更漂亮。
