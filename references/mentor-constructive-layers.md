# 导师建设性建议分层

当任务进入导师修改建议层时，加载此文件。

导师层不等于“把评审意见写得更温和”，而是把已经成立的评审结论分流成不同工作量、不同难度、不同投入回报的改进路径。

## 1. 分层原则

1. 先判 `是否可修复`，再判 `落在哪一层`
2. 同一个问题不能同时混写成低工作量修复和高工作量结构重做
3. `L4` 前沿升级不替代 `L1-L3` 的事实性修复
4. 每层都要写清 `工作量 / 难度 / 预期收益 / 验证动作`

## 2. 四层定义

### `L1` 即时修复

- 适用：局部句子、术语、语气、caption、图表口径轻微回归
- 工作量：低
- 典型动作：强度降级、局限性补写、术语统一、轻量证据重锚
- 典型输出：逐条修改建议卡、句子级替换、图注回归

### `L2` 科学加固

- 适用：讨论链条松散、证据锚点不足、方法或统计解释不够严密、引文依据偏弱
- 工作量：中
- 典型动作：段落级重写、证据链重排、引文升级、方法学依据补强
- 典型输出：导师分层修改建议中的中工作量项、学生执行版中的重点任务

### `L3` 结构修复

- 适用：章节逻辑错位、结果主线混乱、图表与正文脱节、答辩叙事不闭环
- 工作量：高
- 典型动作：小节级重构、图表重排、结果主线重建、补充材料重组
- 典型输出：章节功能重构建议、结构性执行包、答辩主线重建建议

### `L4` 前沿升级

- 适用：创新性判断、最新研究对标、方法是否落后、讨论和答辩需要高水平定位
- 工作量：高到很高
- 典型动作：前沿知识检索、创新定位判断、未来研究升级路径、答辩定位加固
- 典型输出：前沿知识简报、创新定位判断卡、导师摘要中的创新定位段

## 3. 分层决策规则

### 先判问题能否由写作修复

- `可由写作修复`：优先进入 `L1` 或 `L2`
- `可由结构重排修复`：优先进入 `L3`
- `必须补外部前沿判断`：进入 `L4`
- `不可由写作修复`：退回评审或人工补证据，不进入导师修改清单

### 先判收益，再判工作量

同等工作量下，优先处理：

1. 直接影响结论强度的项
2. 直接影响送审/答辩风险的项
3. 直接影响创新定位的项
4. 纯展示增益项

## 4. 导师分层修改建议最少字段

- `定位`
- `问题类型`
- `当前层级`
- `工作量`
- `难度`
- `预期收益`
- `方法学依据`
- `是否需要外部知识检索`
- `建议动作`
- `验证动作`

## 5. 禁止折叠

- 不把 `L1` 的局部润色写成 `L3` 的结构升级
- 不把 `L2` 的科学加固写成已经完成的创新升级
- 不把 `L4` 前沿定位写回论文事实层
