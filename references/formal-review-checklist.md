# 毕业论文形式审查清单

这份清单用于补齐“毕业论文送审 / 预答辩 / 正式答辩前”的形式审查工作。它服务的是**院校模板、版式、编号、互引、导出与提交卫生**，不是专业方法学专项，也不是证据链深审的替代物。

## 多角色规划收口

本轮形式审查规划默认拆成五个角色闭环，再统一收口到这份清单：

- `规范/教务角色`：负责“学校到底要求交什么、按什么顺序交、哪些页必须存在”。
- `文档工程角色`：负责 Word / WPS 的样式、分节、目录域、caption 域、交叉引用、页码域是否健康。
- `图表公式角色`：负责图、表、公式、脚注、尾注、编号和互引是否稳定。
- `导出提交角色`：负责 PDF、盲审匿名、打印、命名、提交包卫生。
- `workflow 集成角色`：负责哪些项适合自动化、哪些项必须人工复核，以及产物落到哪里。

## 1. 使用边界

- 适用于硕士 / 博士学位论文、预答辩稿、送审稿、正式答辩前终稿回归。
- 默认优先检查作者真源文件，优先级通常是 `DOCX / WPS` 高于派生 `PDF`。
- 如果学校或学院提供了最新模板、写作规范、送审须知、封面样例，先冻结这些文件，再做形式审查。
- 如果没有学校模板，只能先执行“通用形式项”，所有精确到字号、字体、页边距、封面字段顺序的判断都应标记为 `待校级模板确认`。
- 这份清单属于“毕业论文场景层”，不要把它混写进 `specialty-*.md` 这类专业方法学专项。

## 2. 标签说明

- `[通用]`：多数院校都适用的通用形式项。
- `[校级]`：必须以学校 / 学院模板或最新通知为准。
- `[自动]`：原则上适合脚本或结构化规则自动检查。
- `[人工]`：需要人工目检、版面判断或结合学校样例判断。
- `[重叠]`：与现有 skill 的图表 / 引文 / 版本回归能力部分重叠，不必重复造轮子。

## 3. 审查前冻结

- [ ] `[通用][自动]` 当前唯一审阅对象已经冻结：文件名、路径、修改时间、导出时间、当前版本号。
- [ ] `[校级][人工]` 已拿到本校 / 本院 / 本专业最新模板、写作规范、送审通知或封面示例。
- [ ] `[通用][自动]` 已确认本轮检查的是 `DOCX / WPS` 真源，还是仅能对 `PDF` 做兼容审查。
- [ ] `[通用][自动]` 已确认论文语言形态：中文论文、英文论文、双语摘要、双语图题 / 表题是否为强制要求。
- [ ] `[通用][自动]` 已确认当前阶段：开题、中期、送审前、外审回复、预答辩、正式答辩前、终稿归档。
- [ ] `[通用][自动]` 已明确“通用规则”和“校级专属规则”的边界，避免混层。

## 4. 前置部分与组成完整性

- [ ] `[通用][自动]` 封面、题名页、原创性声明、授权声明、中文摘要、英文摘要、目录、正文、参考文献、致谢、附录等必需组成部分齐全。
- [ ] `[校级][人工]` 组成顺序符合学校模板，不缺页、不串页、不把可选部分错放到强制部分之前。
- [ ] `[校级][人工]` 封面字段齐全：题目、作者、学号、学院、专业、导师、完成日期、密级 / 分类号 / UDC / 基金信息等按模板出现。
- [ ] `[校级][人工]` 题名页、声明页、授权页的固定措辞与学校样例一致，没有自改模板文字。
- [ ] `[通用][自动]` 中文摘要包含题目、摘要正文、关键词。
- [ ] `[通用][自动]` 英文摘要包含英文题目、英文摘要、英文关键词。
- [ ] `[校级][人工]` 中英文关键词数量、分隔符、大小写、排序方式符合模板要求。
- [ ] `[校级][人工]` 是否需要“符号说明”“缩略语表”“图目录”“表目录”“攻读学位期间成果”等专门页面，已按模板补齐。
- [ ] `[通用][自动]` 目录、图目录、表目录如被要求，已经存在且不是手工伪造文本。

## 5. 章节结构与顺序

- [ ] `[通用][自动]` 正文结构完整，一级到三级标题层级清楚，没有跳级。
- [ ] `[通用][自动]` 标题编号体系一致，例如 `1 / 1.1 / 1.1.1` 或 `第一章 / 1.1 / 1.1.1`，不混用。
- [ ] `[校级][人工]` 各章起始是否强制另起页，是否要求奇偶页规则，符合模板。
- [ ] `[通用][自动]` 参考文献、附录、致谢、成果列表的标题级别与正文主标题级别一致。
- [ ] `[通用][自动]` 附录命名和顺序一致，例如 `附录A / 附录B` 或 `附录1 / 附录2`，不混乱。
- [ ] `[通用][自动]` 没有“目录里有、正文里没有”或“正文里有、目录里没有”的章节。
- [ ] `[通用][人工]` 章节标题文本与目录条目完全一致，没有旧版标题残留。

## 6. 页面版式与排版

- [ ] `[校级][自动]` 纸张大小、页边距、装订边、页眉页脚距离符合模板。
- [ ] `[校级][自动]` 各部分字体、字号、字重、行距、段前段后、首行缩进符合模板。
- [ ] `[校级][人工]` 中文字体、英文字体、数字字体的混排规则符合模板或学院写作规范。
- [ ] `[通用][自动]` 一级、二级、三级标题样式稳定，不因局部手工改字而漂移。
- [ ] `[通用][自动]` 正文段落没有大面积手工空格对齐、空行撑版、连续回车。
- [ ] `[通用][自动]` 页眉、页脚、页码在不同节中的切换正确，没有前后文串节。
- [ ] `[校级][自动]` 前置部分与正文是否要求不同页码样式，如罗马数字 / 阿拉伯数字，已正确实现。
- [ ] `[通用][人工]` 页码连续，不跳号、不重号、不缺页。
- [ ] `[通用][人工]` 页面末尾没有孤行寡行、标题落页末、图表标题与图表主体被拆散等明显版面问题。
- [ ] `[校级][人工]` 题目、摘要、目录、声明页等特殊页面的居中、留白、上下位置符合样例。
- [ ] `[通用][人工]` 中文全角 / 半角、英文半角、数字与单位间距、标点挤压等基础排版细节保持一致。

## 7. 标题样式与自动目录

- [ ] `[通用][自动]` 标题使用了稳定的 Word 样式或等价结构，而不是纯手工加粗放大。
- [ ] `[通用][自动]` 自动目录基于标题样式或域生成，而不是手打目录。
- [ ] `[通用][自动]` 更新目录后，页码、标题文本、层级缩进与正文一致。
- [ ] `[通用][自动]` 图目录、表目录如要求提供，来自 caption / 域而非手抄。
- [ ] `[通用][人工]` 目录中的标题断行、缩进、对齐、引导符样式符合模板。
- [ ] `[通用][自动]` 没有失效的书签、错误的交叉引用或显示 `Error! Bookmark not defined.` 一类域错误。

## 8. 编号体系与互引

- [ ] `[通用][自动]` 章、节、小节编号唯一且连续。
- [ ] `[通用][自动]` 图号唯一，不重号、不漏号。
- [ ] `[通用][自动][重叠]` 表号唯一，不重号、不漏号。
- [ ] `[通用][自动]` 公式编号唯一，不重号、不漏号。
- [ ] `[校级][自动]` 图、表、公式编号格式符合学校要求，例如按章编号或全文连续编号。
- [ ] `[通用][自动][重叠]` 正文中提到的图号、表号、公式号与实际对象一一对应。
- [ ] `[通用][自动]` 附录中的图、表、公式编号与正文编号体系不冲突。
- [ ] `[通用][人工]` 文中“见图X”“如表X所示”“由式(X)可知”等互引位置合理，没有指向错误对象。
- [ ] `[通用][自动]` 图目录、表目录、正文 caption、正文互引四处的编号一致。

## 9. 图、表、公式与注释

- [ ] `[通用][自动][重叠]` 每幅图都有完整图题；如学校要求图注或中英文图题，已按要求补齐。
- [ ] `[通用][自动][重叠]` 每个表都有完整表题；续表、并列表、跨页表的标题和编号规则一致。
- [ ] `[校级][人工]` 图题放上方还是下方、表题放上方还是下方，符合学校模板。
- [ ] `[通用][人工][重叠]` 图中文字、坐标轴、单位、图例在打印和投屏条件下可读。
- [ ] `[通用][人工][重叠]` 图表中的单位、缩写、显著性标记说明完整。
- [ ] `[通用][人工]` 引用他人图片 / 表格 / 公式时，来源标注方式符合学校或期刊化参考规范。
- [ ] `[通用][自动]` 公式使用统一编辑方式，避免正文字符假装公式。
- [ ] `[通用][自动]` 公式编号对齐方式一致，引用方式一致。
- [ ] `[通用][人工]` 变量、符号、上下标、斜体 / 正体、向量 / 标量表示保持一致。
- [ ] `[通用][人工]` 表格跨页时表头重复、边框和对齐稳定，不因分页破坏可读性。

## 10. 摘要、关键词、术语与缩略语

- [ ] `[通用][自动]` 中文摘要、英文摘要与正文题目一致，没有旧版题目残留。
- [ ] `[通用][人工]` 中英文摘要中的专有名词、缩略语、计量单位写法一致。
- [ ] `[校级][人工]` 摘要字数、段落数、是否分段、是否含目的/方法/结果/结论小标题，符合模板。
- [ ] `[校级][人工]` 关键词数量、词性和分隔格式符合模板。
- [ ] `[通用][自动]` 首次出现的缩略语已有全称或符号说明，不前后漂移。
- [ ] `[通用][人工]` 中文与英文术语互译稳定，不出现同一术语多种译法混杂。

## 11. 引文与参考文献格式

- [ ] `[通用][自动][重叠]` 文内每个引文号或作者年份格式统一，不混用两套体系。
- [ ] `[通用][自动][重叠]` 文内有引用的条目，在参考文献列表中能找到；参考文献列表中每条文献都应有正文入口或按学校规则说明。
- [ ] `[通用][自动][重叠]` 数字顺序制文献在正文中的编号次序正确，没有倒序、跳号、复用旧号。
- [ ] `[校级][人工]` 脚注、尾注、文末注如被使用，其使用范围和格式符合学校要求。
- [ ] `[校级][人工]` 中文文献、英文文献、学位论文、专著、标准、网页、会议论文的条目格式符合学校规范。
- [ ] `[通用][自动]` 作者、题名、刊名、年份、卷期、页码、DOI / URL / 访问日期等字段完整度达标。
- [ ] `[通用][人工]` 英文文献大小写、缩写、标点、斜体、作者名缩写规则一致。
- [ ] `[通用][人工]` 中文文献标点、全角半角、责任者写法、出版地 / 出版社写法一致。
- [ ] `[校级][人工]` 参考文献排序规则符合学校要求，例如按引用顺序或字母顺序。

## 12. 附录、成果页、致谢与声明页

- [ ] `[校级][人工]` 致谢是否允许出现、放置位置是否固定，符合学校要求。
- [ ] `[校级][人工]` 攻读学位期间成果页、发表论文列表、专利 / 项目 / 获奖信息如被要求，格式一致。
- [ ] `[通用][自动]` 附录标题、编号、目录入口、页码、正文引用保持一致。
- [ ] `[通用][人工]` 附录中的图表编号、公式编号与正文主编号体系不冲突。
- [ ] `[校级][人工]` 原创性声明、授权声明、保密声明、伦理说明页的固定模板没有被擅自改写。

## 13. Word / WPS 机械健康检查

- [ ] `[通用][自动]` 文档中不存在未接受 / 未拒绝的修订记录。
- [ ] `[通用][自动]` 文档中不存在遗留批注、批注气泡、批注引用锚点。
- [ ] `[通用][自动]` 目录、图目录、表目录、交叉引用、页码域已更新。
- [ ] `[通用][自动]` 没有明显的断裂书签、失效域、失效超链接。
- [ ] `[通用][自动]` 没有大面积手工编号替代自动 caption / 自动目录 / 自动页码。
- [ ] `[通用][自动]` 节分隔符使用合理，没有因错误分节导致页眉页脚、页码、方向混乱。
- [ ] `[通用][自动]` 插图锚定和环绕方式稳定，不会因为重排导致图题错位。
- [ ] `[通用][自动]` 没有隐藏文本、空白文本框、不可见占位对象或模板残留提示语。
- [ ] `[通用][自动]` 文件属性、作者信息、批注作者等元数据如需清理，已按送审要求处理。

## 14. PDF 导出与提交卫生

- [ ] `[通用][自动]` 从真源导出的 PDF 与 Word / WPS 版本一致，没有页码或版面漂移。
- [ ] `[通用][人工]` PDF 中目录、书签、超链接如学校要求保留，已正确生成。
- [ ] `[通用][人工]` PDF 中中文字体、数学公式、特殊符号未乱码。
- [ ] `[通用][人工]` PDF 中图片清晰度可接受，没有压缩过度、裁切错误或整页错位。
- [ ] `[校级][自动]` 盲审版如果需要匿名，封面、声明、页眉页脚、致谢、成果页、文档属性中的可识别信息已处理。
- [ ] `[校级][人工]` 提交文件命名规则、合并 / 拆分规则、是否需去除声明页签名遮挡等符合送审要求。
- [ ] `[校级][人工]` 若需双面打印或胶装，页边距、装订边、跨页表图表现已经目检。
- [ ] `[通用][自动]` 没有多余空白页、测试页、占位页、模板说明页混入最终稿。

## 15. 校级专属覆盖层

以下项目不宜在没有模板的情况下直接下结论，但应作为强制回查项保留：

- [ ] `[校级][人工]` 封面固定字段顺序、行距、居中方式、下划线长度。
- [ ] `[校级][人工]` 中文题目与英文题目是否需要特定字数、换行规则、大小写规则。
- [ ] `[校级][人工]` 学校 / 学院 /学科名称的标准写法、旧称禁用项。
- [ ] `[校级][人工]` 密级、分类号、学校代码、学号、导师职称、日期格式的专门规范。
- [ ] `[校级][人工]` 摘要页、目录页、正文首页、参考文献页是否强制另起页。
- [ ] `[校级][人工]` 参考文献条目具体格式是否采用 GB/T 7714、学校自定义体例或院系变体。
- [ ] `[校级][人工]` 图题 / 表题 / 公式编号是否要求中英文对照。
- [ ] `[校级][人工]` 是否必须提供图目录、表目录、术语表、缩略语表、符号表。
- [ ] `[校级][人工]` 是否要求盲审匿名处理、导师姓名遮蔽、致谢暂缓、成果页删改。
- [ ] `[校级][人工]` 电子版与纸质版是否有不同封面、不同声明页或不同文件拆分要求。

## 16. 与现有 skill 能力的重叠边界

以下形式项已与当前 skill 部分重叠，优先复用现有流程，不必另起炉灶：

- [ ] `[重叠]` 图号、图题、图注、正文互引、图片真源核查。
- [ ] `[重叠]` 表号、表题、正文互引、表格真源提取。
- [ ] `[重叠]` 引文号与参考文献条目映射。
- [ ] `[重叠]` 主文、补充、附录编号与入口一致性。
- [ ] `[重叠]` 旧值残留、版本漂移、HTML / 报告 / 清单回归。

以下形式项当前 skill 明显不足，应视为新增重点：

- [ ] `[新增]` 封面 / 题名页 / 声明页 / 授权页完整性与模板一致性。
- [ ] `[新增]` Word 标题样式、自动目录、caption 域、页码域的机械健康检查。
- [ ] `[新增]` 页边距、装订边、页眉页脚、分节与页码样式的版式检查。
- [ ] `[新增]` 公式编号、公式样式、符号正斜体与上下标一致性。
- [ ] `[新增]` 修订记录、批注、隐藏文本、模板占位语清理。
- [ ] `[新增]` PDF 导出后的字体嵌入、乱码、版面漂移与提交文件命名卫生。

## 17. 自动化优先级建议

### A. 适合优先自动化

- [ ] DOCX 组成部分存在性与顺序初筛。
- [ ] 标题样式、目录域、图目录 / 表目录域存在性。
- [ ] 图、表、公式编号唯一性与编号模式。
- [ ] 正文互引、caption、目录之间的一致性初筛。
- [ ] 页边距、分节、页眉页脚引用、页码域存在性。
- [ ] 修订记录、批注、隐藏文本、模板占位词残留。
- [ ] 参考文献编号顺序、条目完整度、正文入口覆盖率。

### B. 适合“自动初筛 + 人工复核”

- [ ] 封面字段完整但排版是否合样。
- [ ] 中英文字体 / 字号大体合规但局部视觉是否跑偏。
- [ ] 图表清晰度、灰度打印可读性、跨页表现。
- [ ] 公式排版、变量正斜体、上下标视觉质量。
- [ ] PDF 导出后是否存在轻微错位、压缩失真、断行异常。

### C. 不宜直接自动判定

- [ ] 学校样式样例的视觉细节是否完全匹配。
- [ ] 封面留白、上下平衡、居中观感是否合格。
- [ ] 中英文题目、摘要、关键词的人类可读性与学术体例是否自然。
- [ ] 图表是否“看起来规范”但实则影响答辩展示效果。

## 18. 风险分级建议

- `P0`：阻断送审 / 归档 / 答辩提交的问题。典型如必需组成缺失、声明页缺失、目录或页码失效、图表 / 公式重号、修订和批注未清、盲审匿名要求未满足、最终 PDF 明显错页。
- `P1`：高概率被秘书、导师或外审前置退回的问题。典型如封面字段不全、摘要 / 关键词格式不符、标题层级错乱、页眉页脚错误、参考文献体例大面积不一致、图表题位置和编号规则错误。
- `P2`：不直接阻断，但会显著降低成稿质量的清稿问题。典型如局部字号漂移、段前段后不稳、符号正斜体不统一、个别条目标点不一致、图表灰度打印效果一般。

## 19. 建议产物

如果把形式审查正式纳入当前 skill，建议至少落两类产物：

- `reviews/形式审查清单.md`
  - 面向人工核查和逐项勾选。
- `objects/formal_findings.json`
  - 面向脚本输出和回归复用。

推荐最小字段：

- `source_file`
- `template_source`
- `scope`
- `category`
- `check_id`
- `severity`
- `status`
- `automation`
- `evidence`
- `note`
- `needs_manual_confirmation`

## 20. 最低执行顺序

1. 先冻结真源与校级模板。
2. 先扫组成完整性、声明页、目录页、页码、修订记录这类 blocker。
3. 再扫标题样式、自动目录、编号与互引。
4. 再扫图表、公式、参考文献、附录。
5. 最后做 PDF 导出回归和提交卫生。

没有校级模板时，不要伪装成“完整形式审查已完成”；应明确写成“已完成通用形式项初筛，校级细则待模板确认”。

## 21. 形式审查排除项

以下问题不应被误降成“只是格式问题”：

- 研究设计、统计方法、效应量解释、因果识别边界错误。
- 图表语义错误导致结果理解改变，而不是单纯 caption 排版问题。
- 引文错引、弱引、把观察性结果写成因果确认，这属于证据层问题。
- 摘要、正文、补充材料核心数字不一致，这首先是版本真源 / 证据漂移问题。
- 核心结局、样本流程、伦理注册、数据追溯缺失，这首先是深审或合规问题。

形式审查可以先发现这些线索，但不应把它们包装成“清稿后自然解决”的低风险事项。
