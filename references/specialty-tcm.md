# 中医 / 中西医结合专项

最后更新：2026-03
适用范围：中医内科、中医外科、针灸推拿、中西医结合临床各科
主要参考规范：CONSORT for TCM（2017）、STRICTA 2010（针灸）、WHO 传统医学术语标准、中华中医药学会相关指南

## 触发条件

论文涉及以下任一内容时加载：

- 干预：中药（汤剂、中成药、颗粒剂）、针灸、推拿、艾灸、拔罐、穴位贴敷、耳穴、气功、太极
- 理论框架：辨证论治、证候分型、脏腑理论、经络腧穴
- 研究类型：中西医结合治疗、中医药联合西医标准治疗
- 关键词：证候、证型、气虚、阴虚、血瘀、痰湿、肝郁、脾虚等中医术语

## 适用边界

这份手册优先覆盖：

- 中医或中西医结合为主线的临床学位论文
- 中药、针灸、推拿、艾灸等干预研究
- 以辨证论治、证候分型或中西医联合治疗为核心的方法学判断

默认不直接覆盖：

- 纯西医临床论文，只是讨论里顺带提中医观点
- 纯神经工程/影像机制论文，除非中医干预仍是主轴
- 纯院校格式问题或学校送审模板问题

## 研究类型分流

- `RCT / 干预研究`：重点看证候标准、干预细节、对照合理性和盲法诚实性
- `实用性研究 / pragmatic RCT`：重点看个体化辨证与组间可比性的平衡
- `观察性中医临床研究`：重点看暴露定义、辨证一致性和混杂
- `机制探索`：重点看中医干预与客观指标之间的桥接是否过强

## 毕业论文场景重点

- 开题：证候标准、对照设计和疗程参数是否已经明确
- 送审前：穴位、方剂、煎煮和评估指标是否足以复现
- 外审回复：优先回应“证候标准不清”“对照不合理”“客观指标不足”
- 预答辩 / 正式答辩前：必须准备“开放标签”“中医特色结局 vs 客观指标”的安全口径

## 该领域特有的方法学要求

### 辨证论治的标准化问题

中医研究最核心的方法学挑战：个体化治疗与临床研究标准化之间的张力。

**必须核查**：
- 证候诊断标准是否明确（引用哪个版本的诊断标准？国标/行标/自拟？）
- 辨证分型是否有可重复的操作定义
- 如果是固定方案（固定方剂/固定穴位），是否说明了为何不做个体化辨证
- 如果是个体化方案，如何保证组间可比性

**P0 风险**：证候诊断标准完全缺失，或自拟标准无任何依据。

### 对照组设计的特殊性

中医研究的对照设计比西医更复杂，不能用西医标准硬套：

- **安慰针灸**：假针（非穴位浅刺、Park假针）是目前最常用的对照，但其本身可能有生理效应，需在讨论中承认
- **安慰中药**：外观、气味、口感的模拟难度极高，完全匹配几乎不可能，需说明模拟程度
- **空白对照/等待对照**：在某些情况下合理，但需说明为何不做假干预
- **西医标准治疗对照**：中西医结合 vs 单纯西医，是常见且合理的设计

**不能直接判为 P0 的情况**：
- 无法实现双盲（针灸研究中施针者无法盲）→ 应判断是否诚实申报，而非直接判硬伤
- 安慰剂外观不完全一致 → 评估模拟程度是否合理，而非一刀切否定

### 疗程与剂量

- 中药：剂量（克/日）、煎煮方法、服药时间、疗程
- 针灸：穴位名称（标准命名）、针刺深度、手法（补泻）、留针时间、频次、疗程
- 推拿：手法名称、部位、力度（如可量化）、时长、频次

**P1 风险**：只写"针灸治疗"，不写穴位和操作参数。

### 结局指标的选择

- 中医证候积分：需说明量表来源、信效度
- 西医客观指标：优先选用，增加可信度
- 生活质量量表：SF-36、WHOQOL 等通用量表，或领域特定量表
- 中医特色结局：舌象、脉象的客观化测量需说明方法

## 核心结局指标与金标准

- 中医证候积分可以用，但不应孤立承担全部疗效判断
- 西医客观指标、实验室指标、影像或功能量表通常承担更强的答辩和送审说服力
- 针灸、推拿等干预应同时交代中医特色结局与客观结局的层级关系
- 舌象、脉象等中医特色观察如被用于核心论断，必须说明客观化方法或评估一致性

## 学科语域与常用审查用语

- 推荐用语：`证候诊断`、`辨证分型`、`疗效观察`、`客观指标`、`安全性`、`随访`、`临床疗效`
- 不推荐直接进入对外交付物的用语：`模块`、`链路`、`闭环`、`法证`、`原子级`、`阻塞`
- 建议替换：
  - “证据闭环不足” → “证候判断、干预描述与疗效指标之间对应关系未说明清楚”
  - “工程化表述太重” → “应改用证候、疗效、安全性和随访等中医临床研究常用表述”
  - “原子级修改建议” → “逐条修改建议”
- 文件名、页面标题和问题标签优先使用“证候诊断核查”“穴位与方药描述核查”“疗效指标与随访说明”，避免把学生或导师不熟悉的工程话术直接端出去

## 报告规范要点

### CONSORT for TCM（2017扩展版）

在标准 CONSORT 基础上，额外要求：

- 中医诊断标准（疾病诊断 + 证候诊断）
- 干预的完整描述（参照 STRICTA 针灸报告标准）
- 辨证论治的操作化描述
- 对照干预的合理性说明

### STRICTA 2010（针灸专用）

六个核心要素：
1. 针灸的理论依据
2. 穴位选择（名称、定位、深度、刺激方式）
3. 治疗方案（频次、疗程）
4. 其他干预成分（电针参数、艾灸等）
5. 施针者背景
6. 对照干预描述

## 高频风险点

**P0（硬伤）**
- 证候诊断标准完全缺失
- 针灸穴位未按标准命名（只写"相关穴位"）
- 中药方剂组成未列出
- 主要结局只有中医证候积分，无任何客观指标，却宣称疗效确切

**P1（会被追问）**
- 假针对照的生理效应未在讨论中承认
- 辨证分型由同一治疗师完成，存在评估偏倚
- 中药煎煮方法未标准化
- 疗程结束后无随访，却宣称"长期疗效"

**P2（规范加固）**
- 证候量表信效度未报告
- 施针者资质和经验未描述
- 脱落原因未按组分别报告

## 安全定位建议

- 无法实现双盲的研究：定位为"开放标签随机对照研究"，在局限性中诚实说明
- 个体化辨证治疗研究：定位为"实用性随机对照研究（pragmatic RCT）"
- 探索性机制研究（如针灸的神经影像研究）：定位为"初步机制探索"
- 小样本研究：定位为"初步临床证据，需多中心大样本验证"

## 屏蔽说明

激活此文件时，以下通用检查需调整判断标准：

- **双盲要求**：施针者无法盲是领域共识，不直接判 P0；重点检查是否诚实申报、结局评估者是否盲
- **安慰剂标准化**：中药/针灸安慰剂的完美模拟几乎不可能，评估模拟程度是否合理，而非要求完全一致
- **西医病理机制**：不用西医病理机制标准评判中医证候分类的合理性；证候分类有其自身的理论体系
- **设备信号链检查**：仅在论文同时涉及神经工程设备时适用

## 与通用框架/其他专项的优先级

- 与 `clinical-study-types.md` 同时加载时，研究类型先由通用文件分流，本专项补中医领域独有判断
- 与康复或神经工程专项同时加载时，只有当中医干预仍是主轴，本专项优先；设备或信号链细节再由对应专项补充
- 与写作或答辩专项冲突时，术语和安全定位优先保持中医领域可接受表达

## 何时判定为手册不完备

以下情况出现时，应把本手册判为 `partial` 或 `missing`：

- 论文其实是中西医结合下的复杂真实世界因果推断，需要补观察性因果专项
- 论文主轴已经转向神经影像、设备或复杂工程验证，而本手册只够覆盖干预和对照
- 当前论文涉及细分亚专科的强规范要求，而手册还停留在中医临床总论层
- 任务要求处理院校送审/答辩场景规则，而不仅是中医方法学判断
